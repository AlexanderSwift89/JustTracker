Политика конфиденциальности (RU)

JustTracker — приложение для Android, которое записывает GPS-трек по команде пользователя, показывает его на карте и хранит историю треков. Приложение не требует регистрации и не имеет собственных серверов.

1. Какие данные обрабатываются

ДанныеГде хранятсяКому передаются
Координаты, скорость, высота, время точек трека (только между нажатиями «Старт» и «Стоп»)Только на устройстве (локальная база данных приложения)Никому. Разработчик доступа не имеет
Настройки (язык, единицы, тема и т. п.)Только на устройствеНикому
Файлы офлайн-карт регионовВ папке приложения на устройствеНикому

Резервное копирование данных приложения в облако Android отключено: геоданные не покидают устройство. Данные удаляются при удалении трека в приложении или при удалении приложения.

2. Сетевые запросы

Приложение обращается в интернет только к следующим сервисам, всегда по HTTPS. При любом запросе сервер получает IP-адрес устройства.

  • Фрагменты карты (тайлы) — tile.openstreetmap.org (OpenStreetMap Foundation): запрашиваются координаты фрагментов карты, которые вы просматриваете.
  • Офлайн-карты — download.mapsforge.org: загрузка файла выбранного вами региона по вашей явной команде (Настройки → Офлайн-карты). Передаётся только название файла региона.
  • «Интересное рядом» (можно отключить в настройках) — overpass-api.de: запрашиваются объекты в примерном районе около 500 м (сетка, а не точное положение); *.wikipedia.org: запрашивается краткое описание выбранного объекта по названию статьи.

Приложение не содержит рекламных, аналитических и трекинговых SDK, не собирает идентификаторы устройства и не передаёт разработчику никакие данные.

3. Разрешения

  • Геолокация (точная и приблизительная) — запись трека. Используется только пока идёт запись; фоновое разрешение не запрашивается; при записи с выключенным экраном работает служба переднего плана с уведомлением.
  • Уведомления — постоянное уведомление о ходе записи.
  • Интернет — см. раздел 2.

4. Озвучивание

Функция «Прочитать вслух» использует системный синтез речи устройства; текст описания не отправляется разработчику.

5. Дети

Приложение не предназначено для детей младше 13 лет и не собирает данные о них.

6. Изменения и контакты

Privacy Policy (EN)

JustTracker is an Android app that records a GPS track when you tell it to, shows it on a map and keeps a local history. It needs no account and has no servers of its own.

1. Data we process

DataStoredShared with
Coordinates, speed, altitude and timestamps of track points (only between Start and Stop)On the device only (the app’s local database)Nobody. The developer has no access
Settings (language, units, theme, …)On the device onlyNobody
Offline map region filesIn the app’s folder on the deviceNobody

Android cloud backup of the app data is disabled: location data never leaves the device. Data is deleted when you delete a track in the app or uninstall the app.

2. Network requests

The app connects only to the services below, always over HTTPS. Every request reveals the device’s IP address to that server.

  • Map tiles — tile.openstreetmap.org (OpenStreetMap Foundation): the coordinates of the map tiles you are viewing.
  • Offline maps — download.mapsforge.org: downloads the region file you explicitly chose (Settings → Offline maps). Only the file name of the region is sent.
  • Places nearby (can be switched off in Settings) — overpass-api.de: objects in an approximate ~500 m grid cell (not your exact position); *.wikipedia.org: the lead summary of the article you tapped, by article title.

The app contains no advertising, analytics or tracking SDKs, collects no device identifiers and sends nothing to the developer.

3. Permissions

  • Location (precise and approximate) — recording the track. Used only while a recording runs; background location is never requested; with the screen off a foreground service with a notification keeps recording.
  • Notifications — the persistent recording notification.
  • Internet — see section 2.

4. Read aloud

“Read aloud” uses the device’s system text-to-speech engine; the text is not sent to the developer.

5. Children

The app is not directed at children under 13 and collects no data about them.

6. Changes and contact
