# RuStore — декларация разрешений и данных пользователя

Заполняется в RuStore Console на шаге «Безопасность данных» / «Разрешения приложения». Формулировки готовы к вставке.

## 1. Опасные разрешения (из манифеста) и их назначение

| Разрешение | Назначение (текст для формы) |
|---|---|
| `android.permission.ACCESS_FINE_LOCATION` | Запись GPS-трека: координаты сохраняются в локальную базу только между нажатиями «Старт» и «Стоп», чтобы нарисовать маршрут на карте и посчитать дистанцию и скорость. Не передаются разработчику. |
| `android.permission.ACCESS_COARSE_LOCATION` | Запрашивается вместе с точной геолокацией по требованию Android 12+ (пользователь может выбрать приблизительную точность). Используется для той же цели — запись маршрута. |
| `android.permission.POST_NOTIFICATIONS` | Постоянное уведомление во время записи маршрута (время, дистанция, скорость) и кнопки пауза/стоп в уведомлении. |

Обычные разрешения (декларация не требуется, но перечислены для полноты): `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION` — запись при выключенном экране через службу переднего плана типа `location`; `INTERNET`, `ACCESS_NETWORK_STATE` — фрагменты карты, загрузка офлайн-регионов, «Интересное рядом».

Фоновая геолокация (`ACCESS_BACKGROUND_LOCATION`) **не запрашивается**: при выключенном экране работает служба переднего плана с видимым уведомлением.

## 2. Обоснование службы переднего плана (foreground service, type = location)

> Пользователь вручную запускает запись GPS-маршрута кнопкой «Старт». Пока запись идёт (в том числе при выключенном экране или свёрнутом приложении), служба переднего плана получает координаты и сохраняет их в локальную базу; в шторке показывается уведомление с временем записи и кнопками «Пауза»/«Стоп». Служба завершается по нажатию «Стоп». Без неё запись маршрута при выключенном экране невозможна — это основная функция приложения.

## 3. Данные пользователя: сбор, передача, хранение

| Категория | Собирается | Передаётся третьим лицам | Обработка | Комментарий |
|---|---|---|---|---|
| Точное местоположение | Да (только во время записи) | Нет | Хранится только на устройстве, шифрование при передаче не применимо (передачи нет) | Разработчик доступа не имеет; удаляется пользователем в приложении или при удалении приложения |
| Приблизительное местоположение | Да (только при включённой функции «Интересное рядом») | Да — Overpass API (overpass-api.de), Wikimedia (*.wikipedia.org) | Эфемерно, HTTPS | Уходит ячейка сетки ~500 м, не точное положение; функция отключается в настройках |
| IP-адрес (технически при любом сетевом запросе) | Нет (не сохраняется приложением) | Получают серверы: tile.openstreetmap.org, download.mapsforge.org, overpass-api.de, *.wikipedia.org | HTTPS | Стандартное следствие сетевого запроса |
| Персональные данные (имя, e-mail, телефон), идентификаторы устройства, контакты, фото, финансы, здоровье | Нет | Нет | — | Аккаунтов нет, SDK аналитики/рекламы нет |
| Файлы, созданные пользователем (GPX при экспорте) | Формируются по команде пользователя | Только через выбранное пользователем приложение («Поделиться») | FileProvider, временный файл в кэше | — |

**Удаление данных:** любой трек удаляется в приложении (карточка трека → Удалить); полностью — удалением приложения. Резервное копирование в облако Android отключено (`allowBackup=false`, правила извлечения исключают базу, настройки и папку карт).

**152-ФЗ:** приложение не собирает и не передаёт разработчику персональные данные; оператора ПДн в смысле закона нет. Геоданные обрабатываются локально на устройстве пользователя.

## 4. Сетевые хосты (для проверки модератором)

| Хост | Зачем | Когда |
|---|---|---|
| `tile.openstreetmap.org` | Фрагменты онлайн-карты | При просмотре карты без офлайн-региона |
| `download.mapsforge.org` | Файл офлайн-региона | Только по явной команде пользователя в «Офлайн-картах» |
| `overpass-api.de` | Объекты «Интересное рядом» | Только при включённой функции (по умолчанию включена, отключается) |
| `*.wikipedia.org` | Краткое описание объекта | При открытии карточки объекта |

Все соединения — только HTTPS (`usesCleartextTraffic=false`, network security config без пользовательских сертификатов).
