# RuStore — декларация разрешений и данных пользователя

Заполняется в RuStore Console на шаге «Безопасность данных» / «Разрешения приложения». Формулировки готовы к вставке.

## 1. Опасные разрешения (из манифеста) и их назначение

| Разрешение | Назначение (текст для формы) |
|---|---|
| `android.permission.ACCESS_FINE_LOCATION` | Запись GPS-трека: координаты сохраняются в локальную базу только между нажатиями «Старт» и «Стоп», чтобы нарисовать маршрут на карте и посчитать дистанцию и скорость. До начала записи приложение берёт последнее известное системе положение, только чтобы показать пользователя на карте, — оно не сохраняется. Не передаются разработчику. |
| `android.permission.ACCESS_COARSE_LOCATION` | Запрашивается вместе с точной геолокацией по требованию Android 12+ (пользователь может выбрать приблизительную точность). Используется для той же цели — запись маршрута. |
| `android.permission.POST_NOTIFICATIONS` | Постоянное уведомление во время записи маршрута (время, дистанция, скорость) и кнопки пауза/стоп в уведомлении. |

Обычные разрешения (декларация не требуется, но перечислены для полноты): `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION` — запись при выключенном экране через службу переднего плана типа `location`; `INTERNET`, `ACCESS_NETWORK_STATE` — фрагменты онлайн-карты и состояние сети для выбора режима карты (офлайн-регионы скачивает системный менеджер загрузок по команде пользователя).

Фоновая геолокация (`ACCESS_BACKGROUND_LOCATION`) **не запрашивается**: при выключенном экране работает служба переднего плана с видимым уведомлением.

## 2. Обоснование службы переднего плана (foreground service, type = location)

> Пользователь вручную запускает запись GPS-маршрута кнопкой «Старт». Пока запись идёт (в том числе при выключенном экране или свёрнутом приложении), служба переднего плана получает координаты и сохраняет их в локальную базу; в шторке показывается уведомление с временем записи и кнопками «Пауза»/«Стоп». Служба завершается по нажатию «Стоп». Без неё запись маршрута при выключенном экране невозможна — это основная функция приложения.

## 3. Данные пользователя: сбор, передача, хранение

| Категория | Собирается | Передаётся третьим лицам | Обработка | Комментарий |
|---|---|---|---|---|
| Точное местоположение | Да: точки трека — только во время записи; последнее известное положение — для отметки на карте, без сохранения | Нет | Хранится только на устройстве, шифрование при передаче не применимо (передачи нет) | Разработчик доступа не имеет; удаляется пользователем в приложении или при удалении приложения |
| Приблизительное местоположение | Нет (с версии 1.1.2) | Нет | — | Функция «Интересное рядом», которая отправляла примерный район, удалена в 1.1.2. В режиме карты «Онлайн» сервер карты OpenStreetMap получает номера показанных фрагментов карты — вокруг положения пользователя на экране «Запись» (в том числе до записи) и вокруг открытого трека, как при открытии любой веб-карты; в режиме «Офлайн» нет и этого. Если форма требует учитывать запросы карты — отметить «Да: OpenStreetMap Foundation, при показе онлайн-карты» (решение владельца) |
| IP-адрес (технически при любом сетевом запросе) | Нет (не сохраняется приложением) | Получают серверы: tile.openstreetmap.org, download.mapsforge.org | HTTPS | Стандартное следствие сетевого запроса |
| Персональные данные (имя, e-mail, телефон), идентификаторы устройства, контакты, фото, финансы, здоровье | Нет | Нет | — | Аккаунтов нет, SDK аналитики/рекламы нет |
| Файлы, созданные пользователем (GPX при экспорте) | Формируются по команде пользователя | Только через выбранное пользователем приложение («Поделиться») | FileProvider, временный файл в кэше | Удаляется вместе с треком и не позже чем через 24 ч |

**Удаление данных:** любой трек удаляется в приложении (карточка трека → Удалить); полностью — удалением приложения. Резервное копирование в облако Android и перенос на новое устройство отключены (`allowBackup=false`, правила извлечения исключают все данные приложения).

**152-ФЗ:** приложение не собирает и не передаёт разработчику персональные данные; оператора ПДн в смысле закона нет. Геоданные обрабатываются локально на устройстве пользователя.

## 4. Сетевые хосты (для проверки модератором)

| Хост | Зачем | Когда |
|---|---|---|
| `tile.openstreetmap.org` | Фрагменты онлайн-карты | При просмотре карты в режиме «Онлайн» |
| `download.mapsforge.org` | Файл офлайн-региона | Только по явной команде пользователя в «Офлайн-картах» |

Все соединения — только HTTPS (`usesCleartextTraffic=false`, network security config без пользовательских сертификатов). Запросы (включая загрузку регионов) несут технический User-Agent `JustTracker/<версия> (сайт приложения)` (требование правил OSMF); идентификаторов, модели устройства или пользователя нет. Приложение обращается только к хостам этой таблицы; с 1.1.2 это проверяется захватом трафика перед каждым релизом. Координаты и треки на серверы не отправляются; кроме номеров фрагментов карты в режиме «Онлайн», ничего связанного с местоположением устройство не покидает.
