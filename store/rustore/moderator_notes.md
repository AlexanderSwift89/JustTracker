# Комментарий для модератора RuStore

(вставить в поле «Комментарий для модератора» при отправке версии)

Приложение не требует регистрации и аккаунта — все функции доступны сразу после установки.

Как проверить основные функции:
1. При первом запуске выберите язык (русский/английский), затем разрешите геолокацию и уведомления.
2. Вкладка «Запись» → кнопка «Старт». На эмуляторе задайте координаты (Extended controls → Location или `adb emu geo fix <lon> <lat>`); на устройстве достаточно пройти 30–50 м. Панель показывает скорость, дистанцию и время записи; линия маршрута рисуется на карте.
3. «Стоп» → сохранить → откроется карточка трека (карта, статистика, ползунок по треку). Меню «⋮» → «Экспорт GPX» — файл передаётся через системное окно «Поделиться».
4. Офлайн-карты: Настройки → «Управление регионами» → «Мальта (маленький тестовый регион)», 6,7 МБ → «Скачать». Выключите переключатель «Только по Wi-Fi», если тестируете по мобильной сети. После статуса «Готов» включите авиарежим, задайте координаты 35.899, 14.515 и начните запись — карта Валлетты отрисовывается без сети.
5. «Интересное рядом» (метки объектов) требует интернет и отключается в настройках.

Геолокация используется только во время записи, которую пользователь запускает вручную; фоновое разрешение не запрашивается — при выключенном экране работает служба переднего плана с уведомлением. Приложение не зависит от сервисов Google и работает на устройствах без них.

Сетевые хосты: tile.openstreetmap.org (карта), download.mapsforge.org (офлайн-регионы), overpass-api.de и *.wikipedia.org («Интересное рядом»). Только HTTPS.
