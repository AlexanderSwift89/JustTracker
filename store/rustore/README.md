# Материалы для публикации JustTracker в RuStore

Всё, что вводится в RuStore Console, лежит здесь; пошаговая процедура — в `docs/09_release_rustore.md`.

| Файл | Что это |
|---|---|
| `listing_ru.md` | Название, краткое/полное описание, «Что нового», ключевые слова — русский (основной язык карточки) |
| `listing_en.md` | То же на английском (второй язык карточки) |
| `icon-512.png` | Иконка 512×512 PNG без прозрачности (генерируется `make_icon.py` из той же геометрии, что и адаптивная иконка приложения) |
| `screenshots/` | Скриншоты 9:16 (1080×1920), инструкция и скрипт захвата в `screenshots/README.md` |
| `category_age.md` | Категория, возрастной рейтинг по 436-ФЗ с обоснованием |
| `permissions_data_safety.md` | Декларация опасных разрешений, обоснование foreground service, раздел «Безопасность данных», список сетевых хостов |
| `moderator_notes.md` | Комментарий для модератора: как проверить функции без аккаунта, симуляция GPS, тестовый офлайн-регион |
| `contact.md` | Контакты и ссылки, которые требует карточка (сайт, политика, e-mail поддержки — заполняет владелец) |

## Чек-лист перед отправкой на модерацию

Команды и ожидаемый вывод к пунктам о сборке — `docs/09_release_rustore.md` §1.5.

- [ ] `versionCode` больше, чем у версии, опубликованной в RuStore; `versionName` и `CHANGELOG.md` обновлены; тег `vX.Y.Z` — на коммите релиза.
- [ ] «Что нового» (ru + en) — всё, что изменилось с последней **опубликованной** в RuStore версии, включая версии, которые в RuStore не выходили.
- [ ] APK (рекомендуется; AAB требует загрузки подписи через PEPK — `docs/09_release_rustore.md` §1.3) собран **тем же** release-ключом (RuStore не переподписывает) и проверен: `apksigner` — `CN=JustTracker`, SHA-256 `bcb70f4e…ef8709`, не `CN=Android Debug` (D-24); пакет `com.justtracker.app`, новые `versionCode`/`versionName`; не debuggable.
- [ ] Release-APK проверен на устройстве: запуск, выбор языка, запись 30 с, стоп, детали, экспорт GPX, «История» / «Статистика» / «Настройки», офлайн-регион в авиарежиме, `logcat -b crash` пуст; обновление поверх опубликованной версии сохраняет треки (TC-104, с 1.0.3).
- [ ] Проверка на устройстве/эмуляторе **без Google-сервисов** (образ AOSP): геолокация и карта работают.
- [ ] APK и `mapping.txt` сохранены в архив релиза; в консоль загружается именно этот APK.
- [ ] Консоль не предупреждает «Ключ подписи не совпадает…» (появилось — остановиться и перепроверить подпись).
- [ ] Политика конфиденциальности открывается без логина: https://alexanderswift89.github.io/JustTracker/privacy/ (GitHub Pages включён в настройках репозитория).
- [ ] Карточка: название ≤ 50, краткое ≤ 80, полное ≤ 4000 символов; иконка 512×512; ≥ 3 скриншотов 9:16 одной ориентации.
- [ ] Категория и возраст выставлены (`category_age.md`); опасные разрешения задекларированы с назначением (`permissions_data_safety.md`).
- [ ] Комментарий модератору вставлен (`moderator_notes.md`).
- [ ] Контактный e-mail и сайт указаны (`contact.md`).
