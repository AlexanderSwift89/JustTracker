# JustTracker — маркетинговое исследование (бизнес-аналитик)

> Все цифры без ссылки на источник — оценочные гипотезы на основе публичных данных Google Play (число установок, рейтинги, отзывы) и должны быть перепроверены перед принятием финансовых решений.

## 1. Целевая аудитория

| Сегмент | Кто | Зачем | Частота | Устройства | Доля (гипотеза) |
|---------|-----|-------|---------|------------|-----------------|
| **A. Активные любители** (основной для MVP) | 25–50 лет, ходьба, бег, велосипед, скандинавская ходьба | Видеть пройденный маршрут, дистанцию, скорость; вести личную историю без соцсетей | 2–5 раз в неделю | Средний Android (Xiaomi, Samsung A-серия), Android 11–15 | 45 % |
| B. Туристы и походники | 20–55 лет, пешие и вело-походы, грибники | Записать маршрут, чтобы вернуться тем же путём / экспортировать GPX | Сезонно, длинные записи (4–10 ч) | Часто без интернета в поле | 25 % |
| C. Автомобилисты/мото | 25–60 лет | Логировать поездки (пробег, средняя скорость), запоминать маршрут | Ежедневно, короткие записи | Любые | 20 % |
| D. Приватность-ориентированные | Любой возраст, не доверяют облачным трекерам | Хранить геоданные только локально | По ситуации | Часто без Google-аккаунта / с кастомными прошивками | 10 % |

**Основной сегмент MVP — A** (наибольшая частота использования → retention), при этом требования B (офлайн, длинные записи, GPX) и D (без аккаунта) закрываются архитектурно «бесплатно».

## 2. Конкуренты

| OsmAnd | 10M+ | 4.3 | Навигация, офлайн-карты, запись трека — плагин | Freemium, лимит карт | Перегруженный UI, запись спрятана |

## 3. Позиционирование и УТП

**Позиционирование JustTracker (ответвление TrekLog, RuStore):** «Просто трекер: нажал — записал — посмотрел. Без аккаунта, без облака, без рекламы — и без интернета.» Ключевая ценность — **простота и автономность**: приложение делает одно дело, не зависит от сервисов Google и работает там, где нет связи.

УТП:
1. **Ноль регистрации** — работает с первого запуска; интерфейс на русском или английском по явному выбору.
2. **Данные не покидают телефон** — приватность как функция; резервное копирование геоданных в облако отключено.
3. **Офлайн-карты регионов** — скачал округ/страну заранее (файлы Mapsforge, ODbL) и карта работает в лесу, в горах, в роуминге. У Geo Tracker / GPS Logger этого нет, у Komoot/OsmAnd — платно или тяжело.
4. **Работает без сервисов Google** — Huawei/Honor и устройства с AOSP-прошивками, где Strava/Komoot ломаются; важно для RuStore-аудитории.
5. **Автоопределение типа движения**, крупные цифры на ходу, открытый формат GPX — базовые ожидания категории закрыты «бесплатно».

Гипотеза (проверяемо по отзывам RuStore): для сегментов B (туристы) и D (приватность) офлайн-карта и независимость от GMS — главные причины установки; для сегмента A (ежедневные прогулки) — простота записи.

## 4. Приоритизация (MoSCoW)

### MVP 1.0
| Must | Should | Could | Won't |
|------|--------|-------|-------|
| Старт/пауза/стоп записи | Автоопределение типа движения | Общая статистика по всем трекам | Аккаунты, синхронизация |

### Релиз 1.1–1.3 (гипотезы, TrekLog)
- 1.1: **«Интересное рядом» — ступень 1 (метки достопримечательностей OSM + Википедия, карточка) + вариант А (озвучка TTS, авто-озвучка при приближении, opt-in).** Гипотеза: аудиогид «из коробки» без подписки отличает нас от Strava/Komoot (у Komoot — платные Highlights, у Strava — нет); риск — расход трафика и жалобы на приватность → примерный район вместо точки, тумблер в настройках. Также: импорт GPX, авто-пауза при остановке, виджет/quick tile для старта.
- 1.2 (реализовано в TrekLog как «время записи и скорость по участкам»; офлайн-карты перенесены в JustTracker 1.0.0 как файлы регионов, а не кэш тайлов): графики скорости/высоты по треку — открытый кандидат.
- 1.3: цели и достижения, экспорт в CSV, резервная копия в файл (шифрованная).

## 5. Монетизация после MVP и KPI

**Монетизация:** JustTracker 1.x — полностью бесплатно, без покупок и рекламы (в RuStore монетизация с 01.02.2026 доступна только ИП/юрлицам; для физлица-разработчика бесплатная модель — единственный вариант без смены статуса). Гипотеза на будущее — единоразовая покупка «Pro» (графики, авто-бэкап), базовая запись, история и офлайн-карты остаются бесплатными навсегда — это ядро позиционирования.

**KPI для 1.0 (первые 90 дней):**
| Метрика | Целевое значение | Источник |
|---------|------------------|----------|
| Установки | 2 000 | RuStore Console (статистика приложения) |
| Доля установок на устройствах без GMS | измерить (гипотеза ≥ 15 %) | Ручной анализ отзывов / модель устройства в отзывах |
| Доля пользователей, скачавших ≥ 1 регион | ≥ 30 % (гипотеза) | Без аналитики не измеряется напрямую — опрос в отзывах / будущая локальная статистика |
| Средняя оценка | ≥ 4.3 | RuStore Console |
| Крэши по отзывам | 0 воспроизводимых в первые 3 дня | Отзывы RuStore, `mapping.txt` для расшифровки |
| Доля отзывов с упоминанием батареи | ≤ 5 % | Ручной анализ отзывов |

## 6. Риски рынка

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Низкая видимость в RuStore среди крупных брендов | Высокая | ASO по нишевым запросам («gps трекер без регистрации», «офлайн карта маршрут», «записать маршрут gpx»), фокус на офлайне и приватности в описании |
| Отзывы про батарею (характерно для категории) | Средняя | Прозрачная индикация, оптимизация интервалов, FAQ |
| Отклонение на модерации RuStore (декларации, возраст, описание не соответствует функциям) | Средняя | `store/rustore/` — готовые декларации, комментарий модератору с шагами проверки, тестовый регион 6,7 МБ |
| Жалобы на трафик/место из-за размеров регионов (до 1,8 ГБ) | Средняя | Wi-Fi only по умолчанию, размер в диалоге, контроль свободного места, маленькие регионы в каталоге |
| Недоступность download.mapsforge.org или изменение раскладки | Низкая–средняя | Импорт своего `.map` как обход; обновление каталога релизом |
| Ужесточение требований к геолокации в Android | Средняя | Не использовать background-permission, FGS с типом location |
| Копирование функций Geo Tracker | Низкая | Скорость итераций, UX-качество |
