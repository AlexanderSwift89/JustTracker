# JustTracker — PRD (владелец продукта)

## 1. Видение

JustTracker — «просто трекер»: самый простой и **автономный** способ записать свой маршрут на Android. Одна кнопка, карта, понятные цифры. Данные принадлежат пользователю и хранятся только на устройстве; приложение не зависит ни от интернета (офлайн-карты регионов), ни от сервисов Google, ни от аккаунтов. Ответвление TrekLog 1.2.0 для публикации в RuStore.

## 2. Цели MVP 1.0

1. Пользователь может записать трек и увидеть его на карте с первого запуска, без регистрации.
2. Запись устойчива: не прерывается при выключенном экране и сворачивании приложения.
3. Пользователь получает ключевые метрики: мгновенная, средняя и максимальная скорость, дистанция, время записи и время движения, набор высоты, тип движения.
4. Приложение проходит модерацию RuStore без запроса background-location.

### Цели JustTracker 1.0.0 (поверх MVP/1.1/1.2 TrekLog)
5. Карта работает без сети в заранее скачанном регионе (US-19, US-20).
6. Пользователь явно выбирает язык интерфейса — русский или английский (US-18).
7. Все функции работают на устройствах без Google Play Services (US-21).
8. Интерфейс соответствует Material Design 3 (см. `04_ux_design.md` §3, §6).

## 3. Не-цели MVP

- Аккаунты, синхронизация, облако, соцфункции.
- Планирование маршрутов, навигация, собственный тайл-сервер и массовая загрузка растровых тайлов OSM (офлайн решается файлами регионов — US-19).
- iOS, Wear OS, виджеты.
- Реклама, покупки.

## 4. Персоны

- **Алина, 32, ходит пешком/бегает 3 раза в неделю.** Хочет видеть, сколько прошла и с какой скоростью, и не хочет заводить аккаунт в Strava.
- **Игорь, 45, велопоходы по выходным.** Записывает маршрут, чтобы потом экспортировать GPX и поделиться с друзьями.
- **Марат, 38, водитель.** Логирует поездки, важен пробег и средняя скорость; телефон часто в кармане с выключенным экраном.

## 5. Пользовательские истории

Формат критериев: Given / When / Then. Приоритет: P0 — обязательно в 1.0, P1 — желательно, P2 — если останется время.

### Запись

**US-01 (P0). Старт записи.**
Как пользователь, я хочу нажать «Старт», чтобы приложение начало записывать мой маршрут.
- Given разрешение на геолокацию выдано и GPS включён, When нажимаю «Старт», Then появляется уведомление «Запись трека», таймер идёт, на карте появляется маркер моего положения.
- Given разрешение не выдано, When нажимаю «Старт», Then показывается объяснение и системный диалог запроса разрешения; после выдачи запись стартует автоматически.
- Given GPS выключен, When нажимаю «Старт», Then показывается диалог с кнопкой «Открыть настройки геолокации».

**US-02 (P0). Пауза и продолжение.**
- Given запись идёт, When нажимаю «Пауза», Then точки не записываются, время движения не растёт (время записи продолжает идти — см. US-06), уведомление показывает «Пауза».
- Given пауза, When нажимаю «Продолжить», Then запись продолжается новым сегментом (без «прыжка» линии между точкой паузы и точкой продолжения).

**US-03 (P0). Стоп и сохранение.**
- Given запись идёт или на паузе, When нажимаю «Стоп» и подтверждаю, Then трек сохраняется в историю с автоименем «<Тип> — <дата, время>», открывается экран деталей.
- Given трек содержит < 2 точек, When «Стоп», Then трек не сохраняется, показывается сообщение «Слишком мало данных».

**US-04 (P0). Запись при выключенном экране / свёрнутом приложении.**
- Given запись идёт, When выключаю экран на 10 минут и хожу, Then после включения трек содержит точки за все 10 минут.
- Given запись идёт, When система убивает процесс приложения, Then при следующем открытии приложение восстанавливает состояние «идёт запись» (уже записанные точки не теряются) и предлагает продолжить или остановить.

**US-05 (P0). Живая карта.**
- Given запись идёт, When я двигаюсь, Then линия трека продлевается в реальном времени (обновление ≤ 3 с), карта следует за мной.
- Given карта следует за мной, When я сдвигаю карту пальцем, Then автоследование выключается и появляется кнопка «Центрировать», нажатие которой его включает.

**US-06 (P0). Живые метрики.**
- Given запись идёт, Then на экране видны: мгновенная скорость (крупно), **время записи** (основное время: отсчитывается от «Старт» до «Стоп», паузы включаются), дистанция, средняя и максимальная скорость; время движения показывается второстепенной строкой.
- Given нет свежих GPS-данных > 10 с, Then индикатор «Поиск GPS» и мгновенная скорость «—».
- Given запись идёт (1.2), Then линия трека на карте окрашена по скорости участков (легенда «0 … макс.»), тап по линии показывает скорость на этом участке, расстояние от старта и время с начала записи.

### История и детали

**US-07 (P0). Список истории.**
- Given есть сохранённые треки, When открываю «История», Then вижу список (новые сверху) с названием, датой, типом (иконка), дистанцией, временем записи, средней скоростью; второй строкой — время движения и максимальная скорость.
- Given нет треков, Then пустое состояние с подсказкой «Начните первую запись».

**US-08 (P0). Детали трека на карте.**
- When открываю трек, Then карта показывает весь трек целиком (fit bounds), маркеры старта/финиша, линию, окрашенную по скорости, панель статистики: дистанция, время записи, время движения, средняя скорость (по времени движения), макс. скорость, набор/сброс высоты, темп (мин/км) для пеших типов, кол-во точек, время пауз (если были), время старта.
- Given открыта карточка трека, Then под картой есть слайдер по дистанции трека с подписью «<время от старта> · <% дистанции>», кнопки ◀ ▶ (на одну точку) и значения в точке курсора: скорость, расстояние от старта, время суток, высота; маркер курсора движется по линии. When нажимаю на линию трека, Then курсор (и слайдер) переходит в эту точку.

**US-09 (P0). Тип движения.**
- Given трек сохранён, Then тип определён автоматически (пешком / бег / велосипед / авто / другое) на основе скоростей.
- When меняю тип вручную, Then он сохраняется и больше не переопределяется автоматически.

**US-10 (P1). Переименование и удаление.**
- When переименовываю трек, Then новое имя видно в списке.
- When удаляю трек, Then запрашивается подтверждение; после удаления трек исчезает из списка и статистики.

**US-11 (P1). Экспорт GPX.**
- When нажимаю «Экспорт GPX», Then создаётся файл GPX 1.1 и открывается системный диалог «Поделиться».

### Статистика и настройки

**US-12 (P1). Общая статистика.**
- When открываю «Статистика», Then вижу суммарные дистанцию, время, количество треков; разбивку по типам движения; сводку за текущую неделю и месяц.

**US-13 (P1). Настройки.**
- Можно выбрать язык (US-18), единицы (км / мили), тему (системная / светлая / тёмная), открыть «Офлайн-карты» (US-19), увидеть ссылку на политику конфиденциальности и версию.

**US-14 (P0). Разрешения и онбординг.**
- При первом запуске — шаг выбора языка (US-18), затем 1 экран с объяснением, зачем геолокация и уведомления.
- Android 13+: запрос `POST_NOTIFICATIONS` перед первым стартом записи (без него запись всё равно работает, но пользователь предупреждается, что не увидит уведомление).
- Background location **не запрашивается** в MVP.

**US-15 (P1, реализовано в 1.2). Цвет линии по скорости.**
- Линия трека в деталях **и на экране записи** окрашивается по скорости относительно максимума трека (синий → зелёный → жёлтый → оранжевый → красный), рядом с картой — легенда «0 … макс.».
- Скорость по участкам сохраняется вместе с треком (`speedMps` каждой точки) и доступна в истории без пересчёта.

### Интересное рядом (релиз 1.1, «ступень 1 + А»)

**US-16 (P1). Маркеры интересных объектов.**
- Как пользователь, я хочу видеть на карте объекты со статьёй в Википедии вокруг меня и вдоль моего трека, чтобы узнавать, мимо чего прохожу.
- Given включена настройка «Показывать интересные места» (по умолчанию — включена) и есть сеть, When на экране «Запись» известно положение пользователя, Then в радиусе ≈ 1,2 км отображаются метки объектов с тегом `wikipedia` из OpenStreetMap (80 ближайших).
- Given открыта карточка трека, When у трека ≥ 2 точек, Then метки показываются в полосе 400 м вдоль линии трека.
- Given нет сети или сервер недоступен, Then метки просто не появляются (ошибки не показываются; ранее загруженные остаются), повторный запрос не раньше чем через 60 с.
- Given пользователь нажал на метку, Then открывается карточка: название, категория, расстояние (на экране записи), текст описания (лид статьи Википедии), кнопки «Прочитать вслух» и «Википедия», указание источника (CC BY-SA).
- Given описание не загрузилось (нет сети, страница-неоднозначность), Then карточка показывает «Описание недоступно» и ссылку на статью.

**US-17 (P1). Прочитать вслух и авто-озвучка.**
- Как пользователь, я хочу услышать описание объекта, не глядя на экран, чтобы не отвлекаться от движения.
- Given карточка открыта и описание загружено, When нажата «Прочитать вслух», Then текст озвучивается системным TTS на языке статьи (fallback — язык устройства), кнопка меняется на «Стоп», музыка/навигация приглушаются на время речи.
- Given идёт запись и включена настройка «Озвучивать при приближении» (**по умолчанию выключена**), When пользователь оказывается ближе 150 м к объекту, Then объект озвучивается один раз за трек (название + первые предложения, ≤ ~320 символов), даже при выключенном экране.
- Given настройка «Показывать интересные места» выключена, Then авто-озвучка недоступна (переключатель заблокирован) и сетевые запросы к Overpass/Wikipedia не выполняются.

**Не-цели 1.1:** офлайн-кэш описаний, фото объектов, фильтр категорий, полноценный аудиогид с маршрутом — кандидаты в 1.2+ («ступень 2»).

### JustTracker 1.0.0: язык, офлайн-карты, автономность

**US-18 (P0). Явный выбор языка.**
- Как пользователь, я хочу сам выбрать язык интерфейса — русский или английский, чтобы приложение не зависело от языка системы.
- Given первый запуск, Then первый экран онбординга — «Выберите язык» с двумя вариантами (English / Русский), предвыбран язык устройства (если он не русский — English); кнопка «Продолжить» применяет выбор, дальнейший онбординг идёт на выбранном языке.
- Given язык выбран, When открываю Настройки, Then пункт «Язык» первый в списке и показывает текущий выбор; When выбираю другой, Then интерфейс переключается сразу без перезапуска приложения; варианта «Системный» нет.
- Given язык выбран, When приложение перезапущено или устройство перезагружено (Android 8–16), Then язык сохраняется.
- Given язык выбран, Then автоимя нового трека, уведомление записи, язык описаний «Интересного рядом» и fallback озвучки соответствуют выбранному языку, а не языку системы.
- Given Android 13+, Then язык приложения также виден и меняем в системных настройках «Язык приложения» и синхронизирован с выбором в приложении.

**US-19 (P0). Офлайн-карта региона.**
- Как турист, я хочу заранее скачать карту региона, чтобы видеть карту во время записи без интернета.
- Given Настройки → «Офлайн-карты», Then виден каталог регионов (федеральные округа РФ, Крым, Калининград, соседние страны, маленький тестовый регион) с примерным размером, переключатель «Скачивать только по Wi-Fi» (по умолчанию включён) и строка хранилища «Регионы занимают X · свободно Y».
- When нажимаю «Скачать», Then диалог подтверждения с названием, размером и условием сети; после подтверждения статус «В очереди» → «Загрузка… N %» (системное уведомление загрузки) → «Проверка файла…» → «Готов · размер».
- Given «Только по Wi-Fi» и нет Wi-Fi, Then статус «Ожидание Wi-Fi», загрузка стартует сама при подключении. Given нет сети, Then «Ожидание сети».
- Given свободного места меньше размера региона + 200 МБ, When «Скачать», Then загрузка не начинается, показывается «Недостаточно свободного места».
- Given загрузка идёт, When нажимаю «Отменить», Then частичный файл удаляется, регион возвращается в каталог. Given ошибка сети, Then статус с текстом ошибки и кнопка «Повторить».
- Given регион «Готов», When на экране записи или в деталях трека карта попадает в его границы (зум ≥ 8), Then фрагменты карты рендерятся из файла региона без сети; вне границ и на обзорных зумах — онлайн-карта/кэш как раньше. Given авиарежим, Then карта региона отрисовывается полностью, за его границами — пусто/кэш, ошибок нет.
- When удаляю регион (с подтверждением), Then файл удаляется, карта этой области снова требует интернет.
- Given приложение убито во время загрузки, Then загрузка продолжается системой; при следующем запуске статус актуален (проверка файла выполняется автоматически).
- Given подписи на карте, Then они на языке приложения, если файл региона содержит этот язык.

**US-20 (P1). Импорт файла карты.**
- Как опытный пользователь, я хочу импортировать свой файл `.map` (Mapsforge), чтобы использовать карту региона, которого нет в каталоге, или скачанную на компьютере.
- When нажимаю «Импортировать файл .map» и выбираю файл в системном диалоге, Then файл копируется в хранилище приложения, проверяется его заголовок, регион появляется в разделе «Импортированные файлы» со статусом «Готов» и используется как в US-19.
- Given выбранный файл не является картой Mapsforge, Then показывается «Файл не является картой», ничего не сохраняется.
- Given файл `.map` скопирован в папку приложения вручную (USB), Then при запуске он подхватывается автоматически.

**US-21 (P0). Работа без сервисов Google.**
- Как владелец устройства без Google Play (Huawei/Honor, AOSP), я хочу, чтобы приложение полностью работало, чтобы записывать треки на своём телефоне.
- Given устройство без GMS, Then установка из RuStore, запись трека (геолокация через системный LocationManager), карта, офлайн-карты, история, экспорт работают без ошибок и предупреждений о сервисах Google.
- Given устройство с GMS, Then поведение идентично (используется платформенный fused-провайдер Android 12+ или GPS).
- Приложение не содержит зависимостей `com.google.android.gms:*`, Firebase, Play Core.

**US-22 (P0). Явный режим карты: онлайн / офлайн.**
- Как пользователь, я хочу сам решать, откуда карта берёт фрагменты — из интернета или из скачанных регионов, — чтобы приложение работало и онлайн, и полностью автономно, а переключение не происходило «само».
- Given приложение только установлено, Then режим карты — **Онлайн**: фрагменты загружаются из интернета (OpenStreetMap) и кэшируются; карта появляется сразу при запуске при наличии сети.
- Given Настройки → «Режим карты», Then открывается диалог с двумя вариантами — Онлайн / Офлайн — с пояснением каждого и числом готовых регионов; изменение применяется только по кнопке «Применить». Если регионов нет, при выборе «Офлайн» диалог предупреждает, что карта будет пустой (выбор не блокируется).
- Given режим Офлайн, Then карта рендерится только из скачанных регионов (зум ≥ 8) и ранее кэшированных фрагментов; сетевые запросы за фрагментами не выполняются; на экранах записи и деталей рядом с легендой виден бейдж «Офлайн-карта».
- Given режим Онлайн и интернет пропал (нет validated-сети) и есть хотя бы один готовый регион, Then показывается всплывающее окно «Нет подключения к интернету» с кнопками «Переключить: Офлайн» и «Оставить как есть»; без подтверждения режим не меняется. Если регионов нет — окно не показывается.
- Given режим Офлайн и интернет появился, Then показывается окно «Интернет снова доступен» с кнопками «Переключить: Онлайн» и «Оставить как есть».
- Given пользователь нажал «Оставить как есть», Then окно не повторяется, пока состояние сети не изменится ещё раз.
- Given идёт онбординг, Then окна переключения не показываются.
- Выбранный режим сохраняется между запусками.

## 6. Метрики продукта

Без бэкенда и аналитики используем только RuStore Console (установки, удаления, оценки, текст отзывов) и расшифровку крэшей по `mapping.txt` из отзывов. Гипотеза активации: «пользователь завершил хотя бы один трек ≥ 500 м» и «скачал хотя бы один регион» — измеряем косвенно через отзывы.

## 7. Границы релиза 1.0

Входит: US-01…US-09, US-14 (P0) + US-10…US-13 (P1). US-15 — при наличии времени.

**Релиз 1.1:** US-16, US-17 (см. выше). Метрика гипотезы: доля сессий с открытой карточкой объекта; жалобы на расход трафика/батареи в отзывах.

## 8. Требования RuStore

- Аккаунт разработчика RuStore (физлицо — по VK ID с верификацией; для монетизации нужен ИП/юрлицо — не требуется, приложение бесплатное).
- Сборка: AAB или APK, подписанные **собственным постоянным ключом** (RuStore не переподписывает и не хранит ключ); targetSdk 36 (минимум RuStore — 28); native-кода нет (osmdroid/mapsforge — чистая Java), требование 64-bit не затрагивает.
- Приложение не должно ломаться на устройствах без Google-сервисов — выполнено (US-21).
- Карточка: название ≤ 50, краткое описание ≤ 80, полное ≤ 4000 символов (ru + en), иконка 512×512 PNG, 3–10 скриншотов 16:9 или 9:16 — готово в `store/rustore/`.
- Декларация опасных разрешений с назначением (точная/приблизительная геолокация, уведомления) и раздел «Безопасность данных» (геоданные только на устройстве; приблизительный район — Overpass/Wikipedia при включённой функции; IP — серверам карт/загрузок) — текст в `store/rustore/permissions_data_safety.md`, чек-лист в `07_security.md` §5.
- Обоснование foreground service типа `location`: «запись маршрута пользователя по его явной команде».
- Политика конфиденциальности по публичному URL без логина: https://alexanderswift89.github.io/JustTracker/privacy/ (RU + EN, `site/privacy/`).
- Возрастной рейтинг по 436-ФЗ: **12+** — из-за неконтролируемого внешнего контента Википедии в «Интересное рядом» (обоснование в `store/rustore/category_age.md`).
- Категория: Здоровье и спорт (альтернатива: Карты и навигация).
- Комментарий модератору с шагами проверки (симуляция GPS, тестовый регион 6,7 МБ) — `store/rustore/moderator_notes.md`.
