# TrekLog — PRD (владелец продукта)

## 1. Видение

TrekLog — самый простой способ записать свой маршрут на Android: одна кнопка, карта, понятные цифры. Данные принадлежат пользователю и хранятся только на устройстве.

## 2. Цели MVP 1.0

1. Пользователь может записать трек и увидеть его на карте с первого запуска, без регистрации.
2. Запись устойчива: не прерывается при выключенном экране и сворачивании приложения.
3. Пользователь получает ключевые метрики: мгновенная, средняя и максимальная скорость, дистанция, время, набор высоты, тип движения.
4. Приложение проходит проверку Google Play без запроса background-location.

## 3. Не-цели MVP

- Аккаунты, синхронизация, облако, соцфункции.
- Планирование маршрутов, навигация, офлайн-карты.
- iOS, Wear OS, виджеты.
- Реклама, покупки.

## 4. Персоны

- **Алина, 32, ходит пешком/бегает 3 раза в неделю.** Хочет видеть, сколько прошла и с какой скоростью, и не хочет заводить аккаунт в Strava.
- **Игорь, 45, велопоходы по выходным.** Записывает маршрут, чтобы потом экспортировать GPX и поделиться с друзьями.
- **Марат, 38, водитель.** Логирует поездки, важен пробег и средняя скорость; телефон часто в кармане с выключенным экраном.

## 5. Пользовательские истории

Формат критериев: Given / When / Then. Приоритет: P0 — обязательно в 1.0, P1 — желательно, P2 — если останется время.

### Запись

**US-01 (P0). Старт записи.**
Как пользователь, я хочу нажать «Старт», чтобы приложение начало записывать мой маршрут.
- Given разрешение на геолокацию выдано и GPS включён, When нажимаю «Старт», Then появляется уведомление «Запись трека», таймер идёт, на карте появляется маркер моего положения.
- Given разрешение не выдано, When нажимаю «Старт», Then показывается объяснение и системный диалог запроса разрешения; после выдачи запись стартует автоматически.
- Given GPS выключен, When нажимаю «Старт», Then показывается диалог с кнопкой «Открыть настройки геолокации».

**US-02 (P0). Пауза и продолжение.**
- Given запись идёт, When нажимаю «Пауза», Then точки не записываются, время движения не растёт, уведомление показывает «Пауза».
- Given пауза, When нажимаю «Продолжить», Then запись продолжается новым сегментом (без «прыжка» линии между точкой паузы и точкой продолжения).

**US-03 (P0). Стоп и сохранение.**
- Given запись идёт или на паузе, When нажимаю «Стоп» и подтверждаю, Then трек сохраняется в историю с автоименем «<Тип> — <дата, время>», открывается экран деталей.
- Given трек содержит < 2 точек, When «Стоп», Then трек не сохраняется, показывается сообщение «Слишком мало данных».

**US-04 (P0). Запись при выключенном экране / свёрнутом приложении.**
- Given запись идёт, When выключаю экран на 10 минут и хожу, Then после включения трек содержит точки за все 10 минут.
- Given запись идёт, When система убивает процесс приложения, Then при следующем открытии приложение восстанавливает состояние «идёт запись» (уже записанные точки не теряются) и предлагает продолжить или остановить.

**US-05 (P0). Живая карта.**
- Given запись идёт, When я двигаюсь, Then линия трека продлевается в реальном времени (обновление ≤ 3 с), карта следует за мной.
- Given карта следует за мной, When я сдвигаю карту пальцем, Then автоследование выключается и появляется кнопка «Центрировать», нажатие которой его включает.

**US-06 (P0). Живые метрики.**
- Given запись идёт, Then на экране видны: мгновенная скорость (крупно), дистанция, время движения, средняя скорость.
- Given нет свежих GPS-данных > 10 с, Then индикатор «Поиск GPS» и мгновенная скорость «—».

### История и детали

**US-07 (P0). Список истории.**
- Given есть сохранённые треки, When открываю «История», Then вижу список (новые сверху) с названием, датой, типом (иконка), дистанцией, временем, средней скоростью.
- Given нет треков, Then пустое состояние с подсказкой «Начните первую запись».

**US-08 (P0). Детали трека на карте.**
- When открываю трек, Then карта показывает весь трек целиком (fit bounds), маркеры старта/финиша, панель статистики: дистанция, общее время, время движения, средняя скорость (по времени движения), макс. скорость, набор/сброс высоты, темп (мин/км) для пеших типов, кол-во точек.

**US-09 (P0). Тип движения.**
- Given трек сохранён, Then тип определён автоматически (пешком / бег / велосипед / авто / другое) на основе скоростей.
- When меняю тип вручную, Then он сохраняется и больше не переопределяется автоматически.

**US-10 (P1). Переименование и удаление.**
- When переименовываю трек, Then новое имя видно в списке.
- When удаляю трек, Then запрашивается подтверждение; после удаления трек исчезает из списка и статистики.

**US-11 (P1). Экспорт GPX.**
- When нажимаю «Экспорт GPX», Then создаётся файл GPX 1.1 и открывается системный диалог «Поделиться».

### Статистика и настройки

**US-12 (P1). Общая статистика.**
- When открываю «Статистика», Then вижу суммарные дистанцию, время, количество треков; разбивку по типам движения; сводку за текущую неделю и месяц.

**US-13 (P1). Настройки.**
- Можно выбрать единицы (км / мили), тему (системная / светлая / тёмная), увидеть ссылку на политику конфиденциальности и версию.

**US-14 (P0). Разрешения и онбординг.**
- При первом запуске — 1 экран с объяснением, зачем геолокация и уведомления.
- Android 13+: запрос `POST_NOTIFICATIONS` перед первым стартом записи (без него запись всё равно работает, но пользователь предупреждается, что не увидит уведомление).
- Background location **не запрашивается** в MVP.

**US-15 (P2). Цвет линии по скорости.**
- Линия трека в деталях окрашивается по градиенту скорости.

## 6. Метрики продукта

Без бэкенда используем только Play Console: установки, удаления, D1/D7/D30 retention, crash-free, рейтинг и текст отзывов. Гипотеза активации: «пользователь завершил хотя бы один трек ≥ 500 м» — измеряем косвенно через отзывы и опрос в 1.1.

## 7. Границы релиза 1.0

Входит: US-01…US-09, US-14 (P0) + US-10…US-13 (P1). US-15 — при наличии времени.

## 8. Требования Google Play

- targetSdk 36 (требование для новых приложений с 31.08.2026).
- Foreground service с типом `location` → в Play Console заполнить декларацию FGS-типа: «запись маршрута пользователя по его явной команде».
- Data safety: геолокация собирается, хранится только на устройстве, не передаётся третьим лицам; сетевые запросы — только загрузка тайлов карт OpenStreetMap (передаётся IP и координаты тайлов).
- Privacy policy URL обязателен (текст — в `07_security.md`).
- Возрастной рейтинг: 3+ / Everyone.
- Категория: Health & Fitness (альтернатива: Maps & Navigation).
