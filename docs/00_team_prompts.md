# JustTracker — промпты для ролей команды

Проект: **JustTracker** — ответвление TrekLog 1.2.0: «просто трекер». Android-приложение для записи GPS-треков с отображением на карте, статистикой и историей. Ключевая ценность — **простота и автономность**: без аккаунта, без облака, без сервисов Google, с офлайн-картами регионов. Публикация — **RuStore**.

Каждый промпт ниже — самодостаточное задание для роли. Общий контекст (вставляется в начало каждого промпта):

> **Контекст проекта.** Мы разрабатываем Android-приложение JustTracker (пакет `com.justtracker.app`). Пользователь вручную запускает и останавливает запись GPS-трека. Трек рисуется на карте, сохраняется локально на устройстве. Пользователь может смотреть текущий трек, историю треков на карте, мгновенную и среднюю скорость, тип движения (пешком / бег / велосипед / автомобиль — определяется автоматически, с возможностью ручного изменения) и другую статистику; функция «Интересное рядом» (метки Википедии, озвучка) сохранена и отключаема. **Ценность продукта — простота и автономность:** (1) без бэкенда, регистрации и облака — все данные на устройстве; (2) без Google Play Services — геолокация через платформенный `LocationManager`, работа на устройствах без GMS; (3) **офлайн-карты**: пользователь заранее скачивает регион (векторные файлы Mapsforge с download.mapsforge.org) или импортирует свой `.map`; карта работает в явном режиме **Онлайн** (из интернета) или **Офлайн** (только скачанные регионы), режим меняет только пользователь — в настройках или подтверждая всплывающее окно при потере/возврате интернета; (4) **явный выбор языка** интерфейса — русский или английский — при первом запуске и в настройках (без варианта «системный»); (5) соответствие **Material Design 3** (стабильный Compose Material 3, edge-to-edge, predictive back, адаптивная навигация, splash, themed icon); (6) полная готовность к публикации в **RuStore** (подпись своим ключом, декларации разрешений и данных, возраст по 436-ФЗ, политика конфиденциальности на GitHub Pages, материалы карточки в `store/rustore/`). Целевая платформа: Android 8.0+ (API 26+), targetSdk 36. Стек: Kotlin, Jetpack Compose (Material 3), Room, DataStore, `LocationManager`, osmdroid + Mapsforge напрямую (OpenStreetMap / файлы регионов; собственный многопоточный рендер тайлов — ADR-17), AppCompat (per-app locale). Язык документации — русский; идентификаторы в коде и строки по умолчанию — английский, локализация UI на русский.

**Что уже сделано в коде (см. `01_work_plan.md`, этапы 0–5 и J0–J8):** переименование в `com.justtracker.app`, `PlatformLocationSource`, выбор языка (AppCompat per-app locales), M3-выравнивание, офлайн-регионы (`data/maps`, `domain/maps`, `ui/maps`), явный режим карты, CI с подписанной сборкой, сайт `site/`, материалы `store/rustore/`; в 1.0.1 — скелетоны загрузки (`ui/common/Shimmer.kt`), сворачиваемая статистика в деталях трека, собственный рендер офлайн-тайлов (`data/maps/render`). Задача ролей — довести документацию до состояния кода и провести проверки по своим чек-листам.
