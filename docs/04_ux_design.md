# JustTracker — UX/UI спецификация (дизайнер)

## 1. Карта экранов и навигация

```
[Onboarding: Язык → Разрешения] ──(1 раз)──▶ [NavigationSuiteScaffold]
                              ├─ Record   (карта, метрики, Старт/Пауза/Стоп)
                              ├─ History  (список) ──▶ [TrackDetail] ──▶ [RenameDialog], [ActivityTypeSheet], [DeleteDialog], Share(GPX)
                              ├─ Stats    (сводка)
                              └─ Settings ──▶ [OfflineMaps] ──▶ [DownloadDialog], [DeleteDialog], SAF(OpenDocument)
```

- Навигация — M3 navigation suite (`NavigationSuiteScaffold`): при компактной ширине окна (< 600 dp — телефон в портрете, узкий split screen) — `NavigationBar` (4 пункта: `radio_button_checked` Запись, `history` История, `bar_chart` Статистика, `settings` Настройки); при ширине ≥ 600 dp (телефон в landscape, планшет) — `NavigationRail` слева (1.0.2: штатный выбор ставил в landscape нижний бар, отнимавший у карты пятую часть и без того невысокого экрана). На полноэкранных экранах (Onboarding, TrackDetail, OfflineMaps) навигация скрыта (`NavigationSuiteType.None`).
- Во время записи на пункте «Запись» — красная точка-бейдж.
- TrackDetail и OfflineMaps — полноэкранные экраны с `TopAppBar` (назад, заголовок, действия) и `pinnedScrollBehavior` (цвет бара меняется при прокрутке).
- Повторное нажатие вкладки, уже находящейся в стеке (в т. ч. «Запись» после пересоздания activity), возвращает к ней через `popBackStack`, иначе — `navigate` с восстановлением состояния.

## 2. Экраны

### 2.1. Onboarding (первый запуск)

**Шаг 1 — выбор языка (US-18).** Показывается только пока язык не выбран (`AppSettings.language == null`).
```
┌────────────────────────────┐
│  [ (o) language 96dp ]     │
│  Choose your language /    │
│  Выберите язык             │
│  You can change it later   │
│  in Settings.              │
│                            │
│  (●) English               │  ListItem + RadioButton, selectable(role = RadioButton)
│  ( ) Русский               │  подписи-эндонимы одинаковы во всех локалях
│                            │
│  [    Continue    ]        │  FilledButton, full width, 56 dp
└────────────────────────────┘
```
Предвыбор — язык устройства (ru → Русский, иначе English). «Продолжить» сначала сохраняет выбор, затем применяет локаль (AppCompat); на Android < 13 activity пересоздаётся, если выбранный язык отличается от системного, и открывается уже шаг 2 на выбранном языке.

**Шаг 2 — объяснение и разрешения.**
```
┌────────────────────────────┐
│  [иконка приложения 96dp]  │
│  JustTracker                   │
│  Записывайте маршруты.     │
│  Данные остаются на        │
│  вашем телефоне.           │
│                            │
│  ● Геолокация — чтобы      │
│    рисовать ваш маршрут    │
│  ● Уведомления — чтобы     │
│    видеть запись при       │
│    выключенном экране      │
│                            │
│  [   Продолжить   ]  (FilledButton, full width)
└────────────────────────────┘
```
«Продолжить» → запрос location → (Android 13+) запрос notifications → Record. Оба шага применяют `safeDrawingPadding` (edge-to-edge). В невысоком окне (телефон в landscape ≈ 360 dp) содержимое шага прокручивается, кнопка «Продолжить» всегда достижима; пока содержимое помещается, оно центрировано по высоте, как на схеме; в широком окне колонка не шире 560 dp.

### 2.2. Record
```
┌────────────────────────────┐
│ ▣ MapView (весь экран)     │
│   • маркер положения       │
│   • полилиния трека        │
│                  [⌖] ←FAB центрировать (виден, когда follow off)
│                            │
│ [0 ▬▬▬ 18.3 km/h]          │ ← легенда цвета линии (TopStart, §2.8)
│ ┌────────────────────────┐ │
│ │ Скорость на участке  ✕ │ │ ← карточка тапа по линии (над панелью, авто-скрытие 6 с)
│ │ 14.2 km/h · 2.1 km …   │ │
│ └────────────────────────┘ │
│ ┌────────────────────────┐ │
│ │  12.4 km/h ⌁ ● GPS     │ │ ← мгновенная скорость: displayLarge (57sp); нажатие — показать/скрыть ускорение (§2.12)
│ │  ▲ +0.8 м/с² ▁▂▅▃─▔    │ │ ← индикатор ускорения (1.1.0, по умолчанию скрыт)
│ │      00:21:07          │ │ ← ВРЕМЯ ЗАПИСИ — основное время (headlineMedium SemiBold)
│ │     Время записи       │ │   labelMedium
│ │  3.42 km  11.1   18.3  │ │ ← Дистанция / Средняя / Макс. (titleLarge + labelMedium)
│ │  В движении 00:18:32   │ │ ← время движения — второстепенно (bodySmall, onSurfaceVariant)
│ │                  🚲    │ │
│ │  [ ⏸ ]   [ ■ STOP ]    │ │ ← при записи; до старта — одна кнопка [ ● СТАРТ ]
│ └────────────────────────┘ │
└────────────────────────────┘
```
Панель: `Surface` с `surfaceContainer` цветом, alpha 0.92, скругление 24 dp сверху, отступ 16 dp. В широком окне (landscape) панель и баннер «Геолокация выключена» не шире 640 dp (макс. ширина M3 bottom sheet) и стоят по центру — карта видна по бокам; навигация в landscape — rail слева, поэтому карта занимает всю высоту над панелью.

Иерархия времени (1.2): **время записи** — секундомер от «Старт» до «Стоп», паузы включаются (как «Elapsed time» в Strava); тикает по 1-секундному тикеру ViewModel и не зависит от GPS. Тикер работает только во время записи и паузы: в простое (IDLE) экран не перерисовывается вовсе (1.1.2, D-28). **Время движения** — вспомогательная строка мелким шрифтом. В паузе время записи продолжает идти, но, как и все метрики, затемняется (alpha 0.6).

Состояния:
| Состояние | Что показываем |
|-----------|----------------|
| IDLE (нет записи) | Карта центрирована на последнем известном положении (или на весь мир при отсутствии), панель: «Готов к записи», кнопка СТАРТ (72 dp, `primary`, иконка ●) |
| RECORDING | Метрики, легенда скорости (когда есть линия), кнопки ПАУЗА (56 dp, tonal) и СТОП (56 dp, `error`) |
| PAUSED | Метрики затемнены (alpha 0.6), надпись «Пауза», кнопки ПРОДОЛЖИТЬ (primary) и СТОП |
| NO_PERMISSION | Вместо метрик — текст «Нужен доступ к геолокации» + кнопка «Разрешить»; если отказано навсегда — «Открыть настройки» |
| GPS_OFF | Баннер сверху карты: «Геолокация выключена» + кнопка «Включить» (открывает системные настройки) |
| SEARCHING (нет фикса > 10 с) | Индикатор «● GPS» становится серым с текстом «Поиск GPS», скорость «—» |
| Индикатор ускорения открыт (1.1.0) | Строка ускорения под скоростью (в landscape — справа от неё), состояния — §2.12 |

Жесты: drag карты → follow off, FAB «центрировать» появляется с fade-in 200 мс; тап по линии трека → карточка «Скорость на участке» (не отключает follow). **Тап по скорости** (значение, единица, подпись «Скорость») → показать / скрыть индикатор ускорения (§2.12); **тап по остальной панели** (ручка ⌃/⌄, дистанция, время) → раскрыть / свернуть дополнительные показатели. Кнопка СТОП → `AlertDialog` «Завершить запись?» [Отмена] [Завершить].

Смена типа — `ModalBottomSheet` со списком типов (иконка + название), текущий отмечен; содержимое листа прокручивается (в landscape шесть строк не помещаются).

**Landscape (1.0.2).** В широком невысоком окне (ширина > высоты и ≥ 560 dp — телефон в landscape) раскладка двухпанельная: при 45 % высоты карта была бы ≈ 50 dp.
```
┌───────────────────────────────────────────────────────────────┐
│ ←  Бег · 23 сент., 14:33                                   ⋮  │
├───────────────────────────────────┬───────────────────────────┤
│ ▣ MapView (вся высота)            │ ◀ ━━━━━━●━━━━━━━━ ▶      │
│ [0 ▬▬▬ 9.7 km/h]                  │  1:07:32 от старта · 90 % │
│                                   │ 8.8 km/h 9.93 km 15:40 143 m │
│                                   │ 🏃 Бег                [⌄] │
│                                   │ [Дистанция][Время записи] │ ← панель 42 % ширины (300–420 dp),
│                                   │ [Время движ.][Ср. скорость]│   прокручивается целиком
└───────────────────────────────────┴───────────────────────────┘
```
Кнопка ⌄ здесь скрывает только плитки и раздел «Разгоны и замедления» (карта и так на всю высоту). При повороте карта не пересоздаётся (фрагменты, масштаб и положение сохраняются); пока пользователь не двигал карту, трек заново вписывается в новый размер. Открытые диалоги (переименование, удаление, лист типов) и положение курсора поворот переживают — как и возврат в процесс, выгруженный системой в фоне. Четыре значения под слайдером стоят в равных ячейках; в узкой панели при крупном шрифте значение или подпись, не помещающиеся в ячейку, уменьшаются (§4). В диалоге переименования клавиатура в landscape закрывает кнопки — имя сохраняет и клавиша ✓ клавиатуры.

**Сворачиваемая панель статистики.** По умолчанию экран открывается как на схеме (карта 45 % высоты, сетка плиток 55 %). `IconButton` в конце строки типа движения (`keyboard_arrow_down` — «Скрыть статистику, увеличить карту»; `keyboard_arrow_up` — «Показать статистику») сворачивает сетку: карта плавно (250 мс, `animateFloatAsState` веса) занимает всю высоту до панели курсора, а **слайдер и строка значений в точке (§2.9) остаются** — с большой картой по-прежнему можно ходить по треку. Строка типа движения с кнопкой остаётся под панелью курсора, чтобы вернуть плитки одним нажатием. Выбор живёт, пока открыт экран (переживает поворот, `rememberSaveable`); следующий трек снова открывается с плитками.

**Загрузка.** Экран показывает данные, как только трек и его точки прочитаны из БД (сетевых запросов экран не делает). Точки читаются один раз: запись в фоне не перерисовывает открытый трек (1.1.2, D-27). Если чтение длится дольше 100 мс — скелетон экрана (§7): область карты, строка слайдера, строка типа, 3×2 плитки.

### 2.5. Stats
- Верх: три `StatTile` — «Всего треков», «Дистанция», «Время».
- «Эта неделя» / «Этот месяц» — по две плитки.
- «По типам» — список строк: иконка, название, число треков, дистанция.
- Пустое состояние аналогично History; загрузка дольше 100 мс — скелетон в ритме экрана (три плитки, заголовок, три плитки, три строки списка, §7).

### 2.6. Settings
`ListItem`-ы: **Язык** (диалог выбора English / Русский — первый пункт, US-18), Единицы (диалог выбора), Тема (диалог), Порог точности GPS (слайдер 10–100 м), Не гасить экран при записи (switch), **раздел «Офлайн-карты»** (заголовок `labelLarge` цветом `primary`): «Режим карты» (supporting: «Онлайн» / «Офлайн» + «· регионы не скачаны», если офлайн без регионов) → диалог 2.11, «Управление регионами» (supporting: «Регионы не скачаны» / «N регионов · X МБ», плюралы) → экран 2.10, затем Политика конфиденциальности (ссылка), Лицензии открытого ПО (ссылка на `site/licenses/`), Версия, атрибуция «Данные карты © участники OpenStreetMap». Раздел «Интересное рядом» и атрибуция Википедии удалены в 1.1.2 (§2.7).

Строки со switch — один toggleable-таргет (`Modifier.toggleable(role = Role.Switch)`, `Switch(onCheckedChange = null)`): TalkBack читает строку как один переключатель.

### 2.7. Интересное рядом — удалено в 1.1.2

Метки объектов на картах записи и деталей, карточка объекта (`ModalBottomSheet` с описанием из Википедии, «Прочитать вслух», «Википедия»), раздел настроек и авто-озвучка удалены вместе с функцией (`05_architecture.md` ADR-24). Пин `ic_poi_marker` и строки удалены. Спецификация — в истории документа до тега `v1.1.1`. Символы кафе, остановок и музеев на офлайн-карте — часть самой карты Mapsforge, а не эта функция.

### 2.8. Скорость по участкам (1.2)
- **Цвет линии** — по сглаженной скорости каждой точки относительно максимума трека: `#1E88E5` синий (0) → `#43A047` зелёный → `#FDD835` жёлтый → `#FB8C00` оранжевый → `#E53935` красный (макс.), линейная интерполяция (`SpeedColorScale`). Шкала относительная: и у прогулки, и у поездки видно, где было быстрее. Нижняя граница диапазона — 1 м/с, чтобы почти неподвижный трек не был сплошь красным.
- **Легенда** — компактный `Surface` (скругление 12 dp, `surfaceContainer` α 0.92): «0», градиентная полоска 72×6 dp, значение макс. скорости в единицах пользователя. Скрыта, пока максимум = 0.
- **Карточка тапа (экран записи)** — `inverseSurface`: заголовок «Скорость на участке» (labelMedium), значение (titleLarge SemiBold), строка «2.1 km от старта · 00:15:10 с начала записи» (bodySmall), иконка ✕. Тапнутая точка отмечается на карте кольцом 18 dp цвета `onSurface`. Закрывается тапом или через 6 с. В деталях трека вместо карточки — постоянная панель курсора (§2.9).
- В тёмной теме инвертируются только тайлы, цвета линии остаются насыщенными.
- **Окраска по ускорению (1.2.0).** В карточке трека линию можно окрасить по ускорению вместо скорости — переключатель над картой, палитра, легенда и упрощение — §2.13. Экран записи всегда показывает скорость.
- **Длинный трек на обзорном зуме (1.1.2, ADR-26).** Линия рисуется упрощённой, но допуск меньше половины пикселя экрана, поэтому форма на глаз не меняется. Цвет слитого отрезка — средняя скорость его точек, так что переходы цвета сохраняются. При приближении возвращается полная детализация; тап и курсор всегда указывают на точку полной линии.
- **Пунктирная линия (OBS-16).** На некоторых зумах osmdroid рисует частые короткие отрезки с разрывами, похожими на пунктир. Это поведение библиотеки, а не данных: оно есть и в 1.1.1.

### 2.9. Курсор по треку (детали, 1.2)
- Под картой — строка `◀ [Slider] ▶`: слайдер M3 по **дистанции** трека (0…100 %), стрелки — на одну точку назад/вперёд (IconButton 48 dp, `ChevronLeft/Right`, contentDescription «Предыдущая/Следующая точка»).
- Подпись под слайдером (labelLarge, `primary`, по центру): «**00:15:10** от старта · **45 %**» — время с начала записи и доля пройденной дистанции.
- Ряд из четырёх значений (titleMedium SemiBold + labelSmall `onSurfaceVariant`): Скорость · Дистанция (от старта) · Время (суток, HH:mm:ss) · Высота («—», если у точки нет высоты). Когда линия окрашена по ускорению (1.2.0, §2.13), первая ячейка — **Ускорение** в точке, затем Скорость · Дистанция · Высота: время суток уступает место, время от старта есть в подписи.
- Курсор на карте — то же кольцо 18 dp, что и для тапа; движется вместе со слайдером. Тап по линии переносит курсор и слайдер в ближайшую вершину. По умолчанию курсор в начале трека (0 %), панель видна всегда, пока у трека есть точки.
- Слайдер → вершина: ближайшая по накопленной дистанции (бинарный поиск внутри сегмента); при перетаскивании значения обновляются на каждый кадр без сетевых/БД-обращений — все массивы уже в памяти (`TrackLine`). С 1.1.2 курсор — отдельное состояние: ползунок перекомпонует только панель курсора, а карта переставляет лишь кольцо-маркер.

### 2.10. Офлайн-карты (JustTracker 1.0.0, US-19/US-20)

Экран `OfflineMaps` (Настройки → Управление регионами), полноэкранный, `TopAppBar` с «Назад» и действием «Импортировать файл .map» (`file_open`).
```
┌────────────────────────────────────────┐
│ ←  Офлайн-карты                   [📄] │
│ Скачайте регион заранее — карта будет  │  bodyMedium, onSurfaceVariant
│ работать без интернета. Файлы большие. │
│ Скачивать только по Wi-Fi        (●)   │  ListItem + Switch (toggleable)
│ Хранилище                              │
│ Регионы занимают 6,7 МБ · свободно 3,7 ГБ
│ ──────────────────────────────────────  │
│ Доступные регионы                      │  labelLarge, primary
│ [map] Россия — Центральный ФО    [↓]   │  810 МБ
│ [map] Крым                       [↓]   │  36 МБ
│ [✓]   Мальта (тестовый)          [🗑]  │  Готов · 6,7 МБ
│ [map] Финляндия  ▓▓▓▓▓░░░░ 43 % [✕]    │  Загрузка… 43 %  + LinearProgressIndicator
│ [!]   Турция                     [↻]   │  Не удалось скачать — проверьте соединение
│ ──────────────────────────────────────  │
│ Импортированные файлы                  │
│ [✓]   my-region                  [🗑]  │
│ Офлайн-карты: файлы Mapsforge © OSM…   │  bodySmall
└────────────────────────────────────────┘
```

**Состояния региона (RegionStatus):**
| Статус | Ведущая иконка | Supporting | Действие справа |
|---|---|---|---|
| отсутствует | `map` (onSurfaceVariant) | размер из каталога | `download` → диалог «Скачать регион?» (название, размер, условие сети) |
| QUEUED | `map` | «В очереди» / «Ожидание Wi-Fi» / «Ожидание сети» | `close` — отмена |
| DOWNLOADING | `map` | «Загрузка… N %» + `LinearProgressIndicator(progress)` | `close` — отмена |
| VERIFYING | `map` | «Проверка файла…» | `CircularProgressIndicator` 24 dp |
| READY | `check_circle` (primary) | «Готов · размер» | `delete` → диалог «Удалить регион?» |
| ERROR | `error_outline` (error) | текст ошибки: сеть / место / повреждён / неизвестно | каталожный — `refresh` (повторить); импорт — `delete` |

Одноразовые ошибки действий (нет места, ошибка импорта) — `Snackbar`. Во время копирования импортируемого файла — `LinearProgressIndicator` под строкой хранилища, кнопка импорта заблокирована. На устройстве без внешнего хранилища — красная подсказка «нет хранилища для загрузок», кнопки скачивания заблокированы, импорт доступен. Пока каталог и строки регионов не прочитаны (дольше 100 мс) — под заголовком «Доступные регионы» шесть скелетон-строк списка (§7).

**Карта.** Скачанные регионы используются в режиме **Офлайн** (§2.11): тайлы внутри их границ (зум ≥ 8) рендерятся из файлов, остальные — из кэша ранее просмотренных онлайн-тайлов, сеть не используется. В режиме **Онлайн** карта — из интернета, регионы не участвуют. Подписи — на языке приложения, если он есть в файле. В тёмной теме тайлы инвертируются так же, как онлайн (известное ограничение: вода становится коричневой; кандидат — тёмная render-тема Mapsforge).

**Плавность и качество офлайн-карты** (ADR-17). При зуме и перемещении карта ведёт себя как онлайн: на месте ещё не отрисованных фрагментов сразу видны увеличенные/уменьшенные копии соседних (плейсхолдеры osmdroid), которые **заменяются** чёткими тайлами по мере рендера, а не остаются размытыми; фрагменты рендерятся несколькими потоками, кольцо вокруг экрана и предыдущий зум готовятся заранее. Однажды отрисованный фрагмент сохраняется в кэше на диске — повторный просмотр района и уменьшение масштаба идут без задержки. На плотных экранах тайлы рендерятся размером 512 px — подписи и линии такие же чёткие, как у онлайн-карты. Ещё не отрисованный фрагмент показывает стандартную сетку-заглушку osmdroid.

### 2.11. Режим карты: онлайн / офлайн (US-22)

Принцип: **режим меняет только пользователь** — в настройках или подтвердив всплывающее окно; автоматического переключения нет.

**Диалог «Режим карты»** (Настройки → Режим карты), `AlertDialog`:
```

│     Фрагменты карты загружаются из   │  описание (bodySmall, onSurfaceVariant)
│     интернета (OpenStreetMap) и      │
│     кэшируются.                      │
│ ( ) Офлайн                           │
│     Показываются только скачанные    │
│     регионы; карта не использует     │
│     сеть.                            │
│ Готовы 2 скачанных региона.          │  bodySmall; при 0 регионах и выборе «Офлайн» — цвет error:
```

Радиокнопки — `selectableGroup` + `selectable(role = RadioButton)`; ничего не применяется до «Применить».

**Всплывающее окно при смене сети** — `AlertDialog` поверх любого экрана (кроме онбординга):
| Ситуация | Заголовок | Текст | Кнопки |
|---|---|---|---|
| Режим Онлайн, интернет пропал, есть ≥ 1 готовый регион | «Нет подключения к интернету» | «Карта не может загружать новые фрагменты. Переключиться на офлайн-карту из скачанных регионов?» | «Оставить как есть» · «Переключить: Офлайн» |

«Оставить как есть» запоминается для текущего состояния сети: окно не повторяется, пока сеть снова не изменится. Без готовых регионов окно при потере сети не показывается (переключаться не на что).

**Бейдж «Офлайн-карта»** — `Surface` `shapes.small`, `surfaceContainer` α 0.92, иконка `cloud_off` 14 dp + `labelSmall`; на экранах записи и деталей стоит в колонке под легендой скорости (верхний левый угол), чтобы источник карты был виден всегда.

### 2.12. Индикатор ускорения (1.1.0, US-23)

Принципы: скрыт по умолчанию и тогда не занимает места; раскрывается **из скорости** (нажатие на неё); смысл передают знак, стрелка и положение столбика, цвет только помогает; нет данных — «—», а не «0,0».

**Раскрытие.** Блок скорости (значение, единица, строка «Скорость · GPS · тип») — отдельная кнопка (`clickable`, `Role.Button`, рябь в границах блока, скругление `shapes.small`). Пока индикатор скрыт, справа от единицы скорости — значок `show_chart` 16 dp `onSurfaceVariant` (подсказка «здесь есть ещё»). Повторное нажатие скрывает строку. Выбор хранится в DataStore (`show_acceleration`) и действует для следующих записей; по умолчанию — скрыто. Остальная часть панели по-прежнему раскрывает средние/макс./время в движении.

**Портрет (колонка метрик < 380 dp)** — строка под «Скорость · GPS · тип» (`AnimatedVisibility`, раскрытие по высоте + проявление):
```
│  42.7 km/h ⌁                          [⏸] │  ⌁ — только пока индикатор скрыт
│  Скорость  ● GPS  🚗                       │
│  ▲ +1.8 м/с²   ▁▂▅▇▆▃▁ ─ ▔▔▆▇▅          │  стрелка 20 dp; значение titleLarge SemiBold tabular; ед. labelMedium
│  Ускорение · разгон                        │  labelMedium onSurfaceVariant; график 32 dp, остаток ширины
│  3.42 km          00:21:07            [■] │
```
**Landscape (колонка метрик ≥ 380 dp, панель ≈ 480–640 dp)** — блок справа от скорости в той же строке (отступ 20 dp), высота панели не растёт:
```
│  42.7 km/h   ▲ +1.8 м/с²  ▁▂▅▇▆▃▁─▔▔▆▇        [⏸] │
│  Скорость ● GPS 🚗   Ускорение · разгон              │
```

**Состояния:**
| Состояние | Значение | Стрелка | Подпись | График |
|---|---|---|---|---|
| Разгон (a ≥ +0,25 м/с², держится до +0,12) | `+1,8` | `arrow_upward`, «разгон» | «Ускорение · разгон» | живой |
| Замедление (a ≤ −0,25, держится до −0,12) | `−2,4` | `arrow_downward` | «Ускорение · замедление» | живой |
| Равномерно | `+0,1` / `0,0` | `remove`, `onSurfaceVariant` | «Ускорение · равномерно» | живой |
| На месте (все скорости окна < 0,5 м/с) | `0,0` | `remove` | «Ускорение · на месте» | нули |
| Нет оценки: нет доплеровской скорости, приёмник ей противоречит, окно не набрано, фикса нет > 3 с, поиск GPS | `—` | нет | «Ускорение» | секунды без значения — пусто |
| Пауза | `—` | нет | «Ускорение» | затемнён (α 0,6), не пополняется |

Значение — со знаком и одним знаком после запятой, минус — типографский `−` (U+2212, ширина как у «+» в табличных цифрах), около нуля — без знака. Единицы: **м/с²**, в имперской системе — **фут/с²**.

**График за 60 с:** `Canvas` 32 dp, ширина — остаток строки, при < 96 dp (крупный шрифт) скрывается. Нулевая линия 1 dp `outlineVariant`; столбик на секунду (зазор 1 dp), новые справа; вверх — разгон, вниз — замедление; внутри «равномерной» полосы ±0,25 м/с² — `outline`. Масштаб симметричный: ±max(1 м/с², max|a| за минуту, округлённый вверх до 0,5) — шум ходьбы остаётся плоским, резкое торможение помещается целиком. Перерисовка раз в секунду, без анимации.

**Цвета** (`AccelerationColors`, фиксированные, не dynamic color): разгон `#1B5E20` / тёмная тема `#81C784`; замедление `#E65100` / тёмная тема `#FFA726` (до 1.2.0 — `#2E7D32` и `#FFB74D`). Окрашены только стрелка и столбики — графика, ≥ 3:1 к панели (7,5 и 3,6 : 1 в светлой теме, 8,5 и 8,8 : 1 в тёмной); число — `onSurface`, как у скорости. С 1.2.0 те же оттенки красят линию по ускорению в карточке трека (`AccelerationColorScale`, §2.13) и подобраны по имитации дальтонизма (Machado 2009, разница цветов ΔE в CIELAB): при протанопии разгон и замедление прежней светлой пары почти сливались (ΔE 12), новой — 20; в тёмной теме — 41 вместо 30.

**Однократная подсказка.** При первой записи после установки/обновления над скоростью — `PlainTooltip` «Нажмите на скорость, чтобы видеть ускорение» (persistent, закрывается касанием); флаг `acceleration_hint_shown`. Нажатие на скорость тоже отмечает подсказку показанной.

### 2.13. Ускорение в карточке трека (1.2.0, US-24)

Принципы — как у скорости по участкам (§2.8, §2.9): видно, **где** и **как** пользователь разгонялся и замедлялся; смысл передают знак, стрелка и слова, цвет только помогает; нет данных — «—» и нейтральный цвет, а не «0,0»; ничего не появляется у трека, где ускорения нет.

**Переключатель «Скорость | Ускорение».** `SingleChoiceSegmentedButtonRow` из двух сегментов в верхнем левом углу карты, над легендой. Фон неактивного сегмента — `surfaceContainer` α 0,92, как у остальных оверлеев (у M3 он прозрачный и над тайлами нечитаем); галочки нет — выбор показывает заливка `secondaryContainer`. Ширина — по подписям, в пределах ширины карты; при нехватке подпись заканчивается «…». Показан, только если у трека ≥ 10 оценок в движении (`06_system_analysis.md` §3.11 п. 8), иначе линия по скорости, а выбор остаётся для следующих треков. Выбор хранится в DataStore (`detail_line_metric`), по умолчанию — «Скорость». Переключение перекрашивает линию мгновенно, без анимации и без пересоздания линии.

**Оверлей.** Переключатель, легенда выбранной метрики и бейдж «Офлайн-карта» стоят в `FlowRow` (отступы 12 dp, промежутки 8 dp): на широкой карте (landscape) — в один ряд, на узкой — друг под другом. Трек вписывается **ниже** оверлея — один раз, после того как оверлей измерен (без промежуточного вписывания и скачка камеры): карта учитывает измеренную высоту оверлея (сверху отступ не меньше её, снизу — половина обычных 48 dp, там только маркер финиша), оставляя треку не меньше 32 dp высоты; при шрифте 200 % на невысокой карте оверлей может частично лечь на трек — свёрнутая статистика даёт карте всю высоту (OBS-21).

**Палитра линии** (`AccelerationColorScale`, непрозрачные цвета — osmdroid рисует каждый отрезок отдельно со скруглёнными концами, полупрозрачность темнила бы стыки):

| Тема | Разгон | Равномерно / нет оценки | Замедление |
|---|---|---|---|
| Светлая | `#1B5E20` | `#607D8B` | `#E65100` |
| Тёмная (тайлы инвертированы) | `#81C784` | `#90A4AE` | `#FFA726` |

Пары подобраны по имитации протанопии и дейтеранопии (Machado 2009, ΔE в CIELAB): разгон и замедление различаются не меньше чем на ΔE 20, каждый из них от нейтрального — не меньше 30 (проверяет `AccelerationColorScaleTest`); контраст к тайлам — не ниже 3:1 (нейтральный светлой темы — 3,8:1).

Цвет вершины: |a| < 0,25 м/с² или нет оценки — нейтральный; иначе линейно от нейтрального к цвету направления, полный цвет с |a| ≥ S. Шкала S — 95-й процентиль |a| трека в движении, округлённый вверх до 0,5, от 1 до 6 м/с² (§3.11 п. 7): шум ходьбы остаётся серым, а одно резкое торможение не обесцвечивает остальные. На обзорном зуме упрощённая линия не сливает отрезки через границы эпизодов — короткое торможение не растворяется в длинной прямой.

**Легенда** — как у скорости (`surfaceContainer` α 0,92, скругление 12 dp, полоска 72×6 dp): «−3,0 ▬▬▬ +3,0 м/с²», градиент «замедление → нейтральный → разгон»; TalkBack читает легенду одним узлом: «Цвет линии: ускорение, замедление до 3,0 и разгон до 3,0 метра в секунду в квадрате» (с 1.2.0 так же одним узлом читается и легенда скорости).

**Курсор.** Первая ячейка «Ускорение»: значение со знаком и единицей (`titleMedium` SemiBold, табличные цифры, «−» U+2212), под ним подпись со стрелкой 14 dp (`arrow_upward` / `arrow_downward` / `remove`, цвет направления); «—» без стрелки, если в точке нет оценки. TalkBack — словами, как на панели записи: «Ускорение 1,2 метра в секунду в квадрате, замедление» / «Ускорение: нет данных».

**Плитки.** «Макс. разгон» и «Макс. замедление» — парой сразу после «Средняя скорость», чтобы остальные плитки сохранили свои строки; значение со знаком и единицей («+2,4 м/с²», «−4,1 м/с²»), «—» для вида без эпизодов; TalkBack читает единицу словами. Показываются, только если у трека есть ускорение (виден переключатель) и хотя бы один эпизод.

**Раздел «Разгоны и замедления»** — под плитками (портрет — элемент сетки на всю ширину, landscape — в прокручиваемой панели), сворачивается вместе со статистикой:
```
Разгоны и замедления                     ← заголовок списка (labelLarge, primary)
▼  72 → 0 км/ч за 7 с                    ← стрелка цвета направления; bodyLarge
   −2,8 м/с² · 350 м от старта           ← пик эпизода · дистанция от старта; bodyMedium
▲  0 → 72 км/ч за 10 с
   +1,9 м/с² · 0 м от старта
Показать все (N)                         ← TextButton, если эпизодов больше показанных
```
По 3 самых резких эпизода каждого вида, по убыванию |пика|. Скорости — целые в единицах пользователя, длительность — в целых секундах («за 10 с»; от минуты — «мм:сс»). Строка — `ListItem` на прозрачном фоне, при крупном шрифте переносится на две строки; вся строка — одна кнопка и один узел TalkBack: «замедление с 72 до 0 км/ч за 7 секунд, пик 2,8 метра в секунду в квадрате, 350 м от старта». Нажатие переносит ползунок и кольцо к **началу** эпизода (для разгона с места — в точку стоянки, если она сохранена и эпизод не начинается уже с неё); в landscape панель прокручивается вверх, к значениям курсора. «Показать все (N)» — `ModalBottomSheet` с заголовком (`titleLarge`) и прокручиваемым списком всех эпизодов в порядке времени; нажатие на строку переносит курсор и закрывает лист.

**Состояния.**

| Трек | Переключатель | Линия | Плитки и раздел |
|---|---|---|---|
| Поездка, велосипед, бег с доплеровской скоростью | есть | выбранная метрика | есть, если найдены эпизоды |
| Прогулка (точки раз в 2–4 с, ускорение — шум) | есть, если ≥ 10 оценок | в основном нейтральная | обычно нет |
| Без доплеровской скорости (эмулятор без скорости, сетевой провайдер, приёмник «0 при движении») | нет | скорость | нет |
| Записан до 1.2.0 | как выше — ускорение считается из сохранённых точек (§3.11) | | |

## 3. Дизайн-система

- **Цвета:** Material 3 dynamic color (Android 12+), fallback-seed `#1B6E3A` (тёмно-зелёный, ассоциация с маршрутами/природой). Тёмная тема — поддержка обязательна.
- **Цвета типов движения** (используются в иконках и линии трека):
  | Тип | Цвет | Иконка |
  |-----|------|--------|
  | WALK | `#2E7D32` | `directions_walk` |
  | RUN | `#EF6C00` | `directions_run` |
  | BIKE | `#1565C0` | `directions_bike` |
  | CAR | `#6A1B9A` | `directions_car` |
  | OTHER/UNKNOWN | `#546E7A` | `route` |
- **Ускорение (1.1.0, §2.12; 1.2.0, §2.13):** разгон `#1B5E20` / `#81C784` (тёмная), замедление `#E65100` / `#FFA726`, нейтральный (линия) `#607D8B` / `#90A4AE` — стрелка и столбики графика (`AccelerationColors`) и линия по ускорению в карточке трека (`AccelerationColorScale`, один источник цветов).
- **Линия трека:** ширина 6 dp, цвет типа; при записи — `primary`. Маркер положения — круг 14 dp `primary` с белой обводкой 3 dp.
- **Типографика:** явная `Typography` (`ui/theme/Type.kt`, Roboto): `displayLarge` Bold + tabular figures для мгновенной скорости, `headline*` SemiBold; все живые числа (HUD, плитки статистики, курсор) — `TextStyle.tabular()` (`fontFeatureSettings = "tnum"`), чтобы цифры не «прыгали».

- **Иконка приложения:** adaptive icon — фон `#1B6E3A`, передний слой: белая линия маршрута со стартовой точкой и жёлтым (`#FFC857`) кольцом финиша; отдельный однотонный слой `ic_launcher_monochrome` для themed icons (Android 13+). Иконка 512 для магазина генерируется из той же геометрии (`store/rustore/make_icon.py`).
- **Splash:** `androidx.core:core-splashscreen`, тема `Theme.JustTracker.Starting` (фон `ic_launcher_background`, анимируемая иконка — передний слой), удерживается до первой эмиссии настроек, затем `Theme.JustTracker` (AppCompat DayNight — требование per-app locale).
- **Отступы:** сетка 8 dp; внешние 16 dp.

## 4. Доступность
- Все кнопки ≥ 48 dp; главные кнопки записи 56–72 dp.
- `contentDescription` для всех IconButton; для панели метрик — `semantics { contentDescription = "Дистанция 3,4 км, время записи 0:21:07" }`. С 1.1.0 скорость — отдельный узел-кнопка: «Скорость 12,4 км/ч», действие «Показать ускорение» / «Скрыть ускорение»; открытый индикатор зачитывается в описании панели словами — «Ускорение 1,8 метра в секунду в квадрате, разгон» (без `liveRegion`, чтобы не объявлять каждую секунду); график для TalkBack декоративный.
- Контраст текста на панели ≥ 4.5:1 (панель непрозрачная на 92 %).
- **Ускорение в карточке трека (1.2.0, §2.13):** переключатель «Скорость | Ускорение» — группа радиокнопок (`SegmentedButton`); ячейка ускорения под ползунком, плитки «Макс. разгон / замедление» и строки «Разгоны и замедления» читаются словами (единица «метра в секунду в квадрате», направление «разгон» / «замедление»), каждая строка эпизода — один узел-кнопка. Направление передают знак, стрелка и слова, а не только цвет; палитра проверена имитацией протанопии и дейтеранопии (TC-154, `AccelerationColorScaleTest`).
- Поддержка увеличенного шрифта (проверено при 150 % и 200 % в обеих ориентациях, 1.0.2): текст, который должен остаться одной строкой в узкой ячейке — значения и подписи плиток статистики, значения под курсором карточки трека, подписи вкладок навигации, значения панели записи, — `FittedText`: при нехватке ширины уменьшается до 60 % (`TextAutoSize`), затем заканчивается «…»; `maxLines = 1` без подгонки молча обрезал текст («23 сент.» вместо даты и времени, «150» без «м»), перенос ломал длинное слово («Статистик / а»). На панели записи единица измеряется первой, уменьшается значение. Остальной текст (названия, описания, пустые состояния) переносится по словам, экраны прокручиваются.

## 6. Адаптивность, edge-to-edge, predictive back

- **Edge-to-edge** (принудителен с targetSdk 35): `enableEdgeToEdge()`; стиль системных панелей пересчитывается от **темы приложения** (принудительная тёмная тема → светлые иконки статус-бара даже при светлой системе). Экран записи рисует карту под системными панелями, а оверлеи (баннер GPS, легенда, FAB «Центрировать», нижняя панель) сами применяют `safeDrawing`-инсеты. Нижний инсет под `NavigationBar` потребляется навигационным каркасом — панель записи прилегает к бару без пустой полосы, а в режиме rail получает реальный отступ.
- **Адаптивная навигация:** `NavigationSuiteScaffold`, тип по ширине окна (`currentWindowAdaptiveInfoV2`): bar при компактной ширине (< 600 dp), rail при ширине ≥ 600 dp — в том числе телефон в landscape, где штатный `calculateFromAdaptiveInfo` из-за компактной высоты ставил bar.
- **Ориентация (1.0.2, ADR-18):** поворот и изменение размера окна не пересоздают activity — экран, карта, камера, открытые диалоги и листы остаются на месте, меняется только раскладка. Каждый экран проверяется в портрете и landscape телефона: действия достижимы (онбординг, диалоги «Режим карты» и выбора, лист типа, пустые состояния прокручиваются), карта не превращается в полоску (детали — двухпанельная раскладка §2.4), широкие панели ограничены (панель записи ≤ 640 dp). Повторная проверка 1.0.2 на эмуляторе — все экраны, диалоги, листы и системные диалоги разрешений в обеих ориентациях, смена темы и языка, выгрузка процесса, изменение размера окна, шрифт 150–200 % (`08_test_plan.md`, TC-91…95, TC-100…103).
- **Predictive back:** `android:enableOnBackInvokedCallback="true"`; `NavHost` и `ModalBottomSheet` (тип трека) поддерживают жест «назад» с превью; экранов, перехватывающих back, нет.
- **Экраны-списки:** `TopAppBar` + `pinnedScrollBehavior` (History, Stats, Settings, TrackDetail, OfflineMaps).
- **Тёмная тема:** карта инвертируется по теме приложения (не только системной).

## 5. Микровзаимодействия
- Кнопка СТАРТ: при нажатии scale 0.95 → 1.0 (100 мс), затем морф в пару ПАУЗА/СТОП (`AnimatedContent`, 250 мс).
- Точка бейджа на вкладке «Запись» во время записи **мигает раз в секунду** (непрозрачность 1 ↔ 0,3). До 1.1.2 бесконечная пульсирующая анимация держала 60 кадров/с всю запись и мешала UiAutomator ждать простоя (D-29).
- Follow-me: сдвиг на несколько пикселей — мгновенный перенос центра (один кадр), дальше — плавный перелёт 300 мс; при ручном drag — немедленное отключение. До 1.1.2 каждая новая точка запускала секундную анимацию камеры, и карта перерисовывалась непрерывно (D-29).
- Появление новых точек линии — без анимации (производительность).
- Раскрытие панели метрик — `AnimatedVisibility`; переключение вкладок — стандартные переходы `NavHost`.
- Индикатор ускорения (1.1.0): раскрытие/скрытие — `AnimatedVisibility` (по высоте в портрете, по ширине в landscape); смена стрелки — `Crossfade`; график обновляется раз в секунду без анимации.
- Сворачивание/раскрытие статистики в деталях трека — карта и сетка меняют долю высоты плавно (250 мс, `tween`); панель курсора при этом не двигается.
- Переключение «Скорость | Ускорение» в деталях трека (1.2.0) — линия и легенда меняются сразу, без анимации; нажатие на эпизод переносит ползунок и кольцо без анимации камеры.
- Скелетоны загрузки (§7) — полоса блика проходит слева направо за 1,2 с (`infiniteRepeatable`, `LinearEasing`).

## 7. Состояния загрузки: скелетоны («шиммер»)

Везде, где данные читаются или запрашиваются заметное время, вместо пустого экрана или спиннера показывается **скелетон** — макет будущего содержимого в нейтральном тоне с бегущим бликом (`ui/common/Shimmer.kt`). Пользователь видит, что процесс идёт и какой формы будет результат.

| Экран / элемент | Что заменяется | Скелетон |
|---|---|---|
| История | список карточек (чтение БД) | 4 × `SkeletonTrackCard`: круг 40 dp, две строки текста, ряд из трёх значений, строка |
| Детали трека | весь экран до чтения трека и точек | область карты (45 % высоты), строка `◀ ━━━ ▶`, подпись, 4 значения, строка типа, сетка 3×2 `SkeletonStatTile`; в landscape — карта слева на всю высоту, справа строка слайдера, значения, строка типа, 2×2 плитки |
| Статистика | плитки и списки (агрегаты БД) | 3 плитки · заголовок · 3 плитки · заголовок · 3 строки |
| Офлайн-карты | строки каталога регионов | 6 × `SkeletonListItem` под заголовком «Доступные регионы» |

Правила:
- **Задержка 100 мс** (`rememberSkeletonVisible`): если данные пришли раньше, скелетон не показывается вовсе — нет «мигания» на быстрых загрузках.
- Цвета из темы: подложка `surfaceContainerHigh`, блик `surfaceContainerLowest`; в тёмной теме — те же роли. Скругления — токены `Shapes` (`extraSmall` для строк текста, `small`/`medium` для блоков, `CircleShape` для иконок).
- Размеры повторяют реальные элементы (высота строки ≈ высота строки текста, плитка = `StatTile` с внутренними отступами 16/12 dp), чтобы замена контентом не сдвигала макет.
- Доступность: контейнер скелетона объявляет `contentDescription` «Загрузка…» (`cd_loading`) один раз, декоративные прямоугольники скрыты от TalkBack (`clearAndSetSemantics`).
- Скелетон никогда не блокирует навигацию (кнопка «Назад» и меню доступны); ошибка/пустое состояние заменяют его, как только известны.
- Не используется там, где индикация прогресса содержательна: загрузка региона (`LinearProgressIndicator` с процентами), проверка файла (`CircularProgressIndicator`), импорт.
