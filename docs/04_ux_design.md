# TrekLog — UX/UI спецификация (дизайнер)

## 1. Карта экранов и навигация

```
[Onboarding] ──(1 раз)──▶ [MainScaffold + BottomNav]
                              ├─ Record   (карта, метрики, Старт/Пауза/Стоп)
                              ├─ History  (список) ──▶ [TrackDetail] ──▶ [RenameDialog], [ActivityTypeSheet], [DeleteDialog], Share(GPX)
                              ├─ Stats    (сводка)
                              └─ Settings
```

- Bottom navigation: 4 пункта с иконками Material Symbols: `radio_button_checked` (Запись), `history` (История), `bar_chart` (Статистика), `settings` (Настройки).
- Во время записи на пункте «Запись» — красная точка-бейдж.
- TrackDetail — полноэкранный экран с TopAppBar (назад, название, меню ⋮).

## 2. Экраны

### 2.1. Onboarding (первый запуск)
```
┌────────────────────────────┐
│  [иконка приложения 96dp]  │
│  TrekLog                   │
│  Записывайте маршруты.     │
│  Данные остаются на        │
│  вашем телефоне.           │
│                            │
│  ● Геолокация — чтобы      │
│    рисовать ваш маршрут    │
│  ● Уведомления — чтобы     │
│    видеть запись при       │
│    выключенном экране      │
│                            │
│  [   Продолжить   ]  (FilledButton, full width)
└────────────────────────────┘
```
«Продолжить» → запрос location → (Android 13+) запрос notifications → Record.

### 2.2. Record
```
┌────────────────────────────┐
│ ▣ MapView (весь экран)     │
│   • маркер положения       │
│   • полилиния трека        │
│                  [⌖] ←FAB центрировать (виден, когда follow off)
│                            │
│ ┌────────────────────────┐ │
│ │  12.4 km/h   ● GPS     │ │ ← мгновенная скорость: displayLarge (57sp)
│ │  ────────────────────  │ │
│ │  3.42 km   00:18:32    │ │ ← дистанция / время движения (titleLarge)
│ │  ср. 11.1 km/h  🚲     │ │ ← средняя + иконка типа (bodyLarge)
│ │                        │ │
│ │  [ ⏸ ]   [ ■ STOP ]    │ │ ← при записи; до старта — одна кнопка [ ● СТАРТ ]
│ └────────────────────────┘ │
└────────────────────────────┘
```
Панель: `Surface` с `surfaceContainer` цветом, alpha 0.92, скругление 24 dp сверху, отступ 16 dp.

Состояния:
| Состояние | Что показываем |
|-----------|----------------|
| IDLE (нет записи) | Карта центрирована на последнем известном положении (или на весь мир при отсутствии), панель: «Готов к записи», кнопка СТАРТ (72 dp, `primary`, иконка ●) |
| RECORDING | Метрики, кнопки ПАУЗА (56 dp, tonal) и СТОП (56 dp, `error`) |
| PAUSED | Метрики затемнены (alpha 0.6), надпись «Пауза», кнопки ПРОДОЛЖИТЬ (primary) и СТОП |
| NO_PERMISSION | Вместо метрик — текст «Нужен доступ к геолокации» + кнопка «Разрешить»; если отказано навсегда — «Открыть настройки» |
| GPS_OFF | Баннер сверху карты: «Геолокация выключена» + кнопка «Включить» (открывает системные настройки) |
| SEARCHING (нет фикса > 10 с) | Индикатор «● GPS» становится серым с текстом «Поиск GPS», скорость «—» |

Жесты: drag карты → follow off, FAB «центрировать» появляется с fade-in 200 мс. Кнопка СТОП → `AlertDialog` «Завершить запись?» [Отмена] [Завершить].

### 2.3. History
- `LazyColumn` карточек (`ElevatedCard`, отступ 12 dp):
  ```
  ┌────────────────────────────────┐
  │ 🚶 Пешком · 19 сен, 10:14      │  ← иконка типа в цветном круге 40 dp + название (titleMedium)
  │ 5.2 km   52:10   6.0 km/h      │  ← bodyMedium, три колонки
  └────────────────────────────────┘
  ```
- Пустое состояние: иллюстрация-иконка `route` 96 dp, текст «Пока нет треков», подпись «Нажмите Старт на вкладке Запись».
- Долгое нажатие → контекстное меню: Переименовать, Удалить.

### 2.4. TrackDetail

┌────────────────────────────┐

├────────────────────────────┤

│  Дистанция   Время движ.   │  сетка 2×N `StatTile` (label labelMedium, value headlineSmall)

│  Ср. скорость Макс. ск.    │

│  Набор высоты Сброс        │
│  +48 m       −51 m         │
│  Темп        Точек         │

Смена типа — `ModalBottomSheet` со списком типов (иконка + название), текущий отмечен.

### 2.5. Stats
- Верх: три `StatTile` — «Всего треков», «Дистанция», «Время».
- «Эта неделя» / «Этот месяц» — по две плитки.
- «По типам» — список строк: иконка, название, число треков, дистанция.
- Пустое состояние аналогично History.

### 2.6. Settings
`ListItem`-ы: Единицы (диалог выбора), Тема (диалог), Порог точности GPS (слайдер 10–100 м), Не гасить экран при записи (switch), Политика конфиденциальности (ссылка), Версия.

## 3. Дизайн-система

- **Цвета:** Material 3 dynamic color (Android 12+), fallback-seed `#1B6E3A` (тёмно-зелёный, ассоциация с маршрутами/природой). Тёмная тема — поддержка обязательна.
- **Цвета типов движения** (используются в иконках и линии трека):
  | Тип | Цвет | Иконка |
  |-----|------|--------|
  | WALK | `#2E7D32` | `directions_walk` |
  | RUN | `#EF6C00` | `directions_run` |
  | BIKE | `#1565C0` | `directions_bike` |
  | CAR | `#6A1B9A` | `directions_car` |
  | OTHER/UNKNOWN | `#546E7A` | `route` |
- **Линия трека:** ширина 6 dp, цвет типа; при записи — `primary`. Маркер положения — круг 14 dp `primary` с белой обводкой 3 dp.
- **Типографика:** Material 3 default (Roboto); мгновенная скорость — `displayLarge` с `FontWeight.Bold`, tabular figures.
- **Скругления:** карточки 16 dp, панель записи 24 dp, кнопки — круглые.
- **Отступы:** сетка 8 dp; внешние 16 dp.

## 4. Доступность
- Все кнопки ≥ 48 dp; главные кнопки записи 56–72 dp.
- `contentDescription` для всех IconButton; для панели метрик — `semantics { contentDescription = "Скорость 12 км/ч, дистанция 3,4 км" }`.
- Контраст текста на панели ≥ 4.5:1 (панель непрозрачная на 92 %).
- Поддержка увеличенного шрифта: значения не обрезаются, используется `autoSize`-подобное уменьшение до `displayMedium`.

## 5. Микровзаимодействия
- Кнопка СТАРТ: при нажатии scale 0.95 → 1.0 (100 мс), затем морф в пару ПАУЗА/СТОП (`AnimatedContent`, 250 мс).
- Пульсация точки бейджа на вкладке «Запись» (1 с, infinite).
- Follow-me: камера анимируется к новой точке 300 мс; при ручном drag — немедленное отключение.
- Появление новых точек линии — без анимации (производительность).
